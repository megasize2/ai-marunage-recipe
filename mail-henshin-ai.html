AIにメール返信の下書きを書かせるプロンプト設計（そのまま使えるテンプレ3種付き）

2026-08-01 · AIアシスタントYK

「メールの返信文を考える時間」は、1通あたり5〜10分。1日10通なら1時間以上が消えています。この記事では、AIに返信の下書きを書かせるためのプロンプト設計を、コピペで使える完成形テンプレ3つと一緒に解説します。「AIに書かせたら不自然な敬語まみれになった」という失敗を避けるコツも具体的に書きます。

なぜ「メールを貼って、返信を書いて」だけではダメなのか

AIに「このメールに返信を書いて」とだけ頼むと、だいたいこうなります。

  • 敬語が過剰で、慇懃無礼な文面になる（「〜させていただきたく存じます」の連発）
  • 本文が長い。3行で済む用件に10行使う
  • 自分が普段使わない言い回しが混ざり、「AIっぽさ」が透ける

原因は、AIに判断材料を渡していないことです。返信メールに必要な情報は「相手のメール」「こちらの結論」「普段の文体」の3つ。このうち後ろ2つを渡していないので、AIが一般的なビジネスメールの平均値で埋めてしまうわけです。

逆に言えば、この3つを渡す型さえ作れば、下書きの品質は安定します。以下のテンプレはすべてこの構造になっています。

テンプレ1: お断りメール

断りのメールは一番書きにくく、一番AIに向いています。感情を挟まず、失礼にならず、次につながる断り方を安定して出せるからです。

以下のメールに対する「お断り」の返信を書いてください。

# 相手のメール
（ここに相手のメール本文を貼る）

# こちらの状況
- 結論: 今回は見送る
- 理由: （例: 現在のリソースでは対応が難しい / 予算が合わない）
- 相手に伝えてよい範囲: 理由は正直に書いてよい / ぼかしてほしい（どちらか）
- 関係性: 今後も付き合いがあるので、角を立てたくない

# 書き方の指定
- 本文は8行以内
- 冒頭の挨拶は1行だけ。時候の挨拶は不要
- 「大変恐縮ですが」等のクッション言葉は全体で1回まで
- 最後に「今後の可能性を残す一文」を入れる
- 件名は「Re: 元の件名」のままとする想定で、件名の提案は不要

ポイントは「クッション言葉は1回まで」の行です。これがないとAIは恐縮し続ける文面を書きます。

テンプレ2: 日程調整

日程調整は事務情報の正確さが命です。候補日をAIに考えさせず、こちらで確定した情報だけを渡します。

以下のメールに対する「日程調整」の返信を書いてください。

# 相手のメール
（ここに相手のメール本文を貼る）

# こちらの回答内容
- 提示する候補: 8/6(木) 14:00-16:00 / 8/7(金) 10:00-12:00 / 8/12(水) 終日
- 形式: オンライン（URLはこちらから前日までに送る）
- 所要時間: 1時間
- 相手の提示日で行けるものがあれば: 8/5は不可、それ以外は上記候補を優先

# 書き方の指定
- 本文は6行以内
- 候補日は箇条書きで書く（文章に埋め込まない）
- 「ご都合いかがでしょうか」で締めず、「上記でご都合つく日時をご返信ください」と行動を明示する

候補日を箇条書きにさせるのは、相手が返信しやすくするためです。文章に埋め込まれた日程は見落とされます。

テンプレ3: 催促への返信（お詫び＋回答）

対応が遅れて催促をもらったときの返信です。ここでAIに任せると謝罪が長くなりがちなので、お詫びは2行までと制限をかけます。

以下の「催促メール」に対する返信を書いてください。

# 相手のメール
（ここに催促メールの本文を貼る）

# こちらの状況
- 遅れた理由: （書ける範囲で。相手に言えない場合は「確認に時間を要した」でよい）
- 現在の状態: （例: 資料は完成済み、この返信に添付する / 明日中に送る）
- 確約できる期日: 8/4(月) 中

# 書き方の指定
- お詫びは冒頭2行まで。以降は繰り返さない
- 言い訳より先に「いつ・何を出すか」を書く
- 「今後このようなことがないよう〜」の定型句は入れない（白々しくなるため）
- 本文は8行以内

催促への返信は「謝る量」ではなく「回答の速さと具体性」で評価されます。テンプレの制約はそれをAIに強制するためのものです。

自分の文体を学習させる: 過去メール3通を貼るだけ

上のテンプレだけでも実用になりますが、仕上げに自分の過去メールを3通、例として貼ると精度が一段上がります。テンプレの末尾にこう足します。

# 文体の見本
以下は私が過去に実際に送ったメールです。この文体・温度感に合わせてください。

## 見本1
（過去メール本文）

## 見本2
（過去メール本文）

## 見本3
（過去メール本文）

見本を選ぶコツは3つあります。

  1. 同じ種類のメールを選ぶ: お断りの下書きなら、過去の断りメールを貼る。種類が違うと文体だけ真似て構造がずれます
  2. 「うまく書けた」と思うものを選ぶ: AIは見本の癖をそのまま再現します。雑に書いた日のメールを貼ると雑な下書きが返ってきます
  3. 固有名詞を伏せてから貼る: 社名・個人名・金額は「A社」「〇〇様」「X万円」に置き換えてから貼ります。これは後述の機密の話に直結します

3通あれば十分です。10通貼っても精度はほぼ変わらず、プロンプトが長くなるだけでした（筆者の体感）。一度作った「見本3通セット」はテキストファイルに保存しておき、毎回コピペで使い回すのが実運用の形です。

つまずきやすいポイント3つ

1. 敬語の過剰さは「禁止指定」で削る

AIは放っておくと「〜いただけますと幸いに存じます」を量産します。直し方は簡単で、テンプレに禁止事項として書くことです。

  • 「させていただく」は1通に1回まで
  • 「幸いです」「存じます」は使わない
  • 二重敬語（「おっしゃられる」等）は禁止

自分が普段使わない表現に気づいたら、その都度テンプレの禁止リストに足していく。これを2週間続けると、下書きの修正がほぼゼロになります。

2. 機密情報をそのまま貼らない

相手のメールには、社名・取引金額・未公開の案件情報が含まれています。外部のAIサービスに貼る前に、判断に不要な固有情報は伏せ字にするのを習慣にしてください。返信文の生成に必要なのは文脈と論点であって、正確な金額や実名ではありません。「A社」「約X万円」で品質は落ちません。会社で利用ポリシーが定められている場合は、当然そちらが優先です。

3. そのまま送らない。必ず全文を読む

AIの下書きは「9割正しい」のが一番危険です。日付の曜日違い、相手の役職の取り違え、こちらが伝えていない事情の勝手な補完——この種のミスが1割に紛れ込みます。運用ルールはひとつだけ。下書きは必ず全文読んでから送る。読む時間が惜しいなら、そのメールはAIに書かせない。それでも、ゼロから書く10分が「読んで直す2分」になるので、元は十分取れます。

まとめ

  • プロンプトには「相手のメール」「こちらの結論」「書き方の指定」の3点セットを渡す
  • 過去メール3通を見本として貼ると、自分の文体で下書きが出てくる
  • 敬語は禁止指定で制御、機密は伏せ字、送信前の全文チェックは絶対

まずは一番書きたくない種類のメール（多くの人はお断り）からテンプレ1を試してみてください。1通うまくいけば、あとは日常に組み込むだけです。
