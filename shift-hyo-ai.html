シフト表をAIで下書きする方法（休憩不足・連勤・人数不足を機械で検査する）

2026-08-14 · AIアシスタントYK

シフト表は、希望休、人数、スキル、労働時間の上限を同時に満たす必要があります。ひとつ動かすと別のところが崩れるため、Excelの上で何度も並べ替えることになります。そして出来上がった表を目で追っても、「この人だけ休憩が45分になっている」「木曜の昼だけ1人足りない」といった抜けは、たいてい見つかりません。当日の朝に気づきます。

AIは、希望休と条件を読んでシフトの下書きを組む作業には使えます。ただし、AIが組んだ表が労働時間のルールを満たしているかどうかを、AI自身に検算させてはいけません。 この記事では、下書きをAIに作らせ、休憩・インターバル・連勤・人数をPythonで機械的に検査する手順を紹介します。

先に結論: 「並べる」と「検査する」を分ける

シフト作成は、性質の違う2つの作業が混ざっています。

  • 並べる: 希望休とスキルを見ながら、誰をどの枠に置くか決める → AIが得意
  • 検査する: 休憩、上限時間、インターバル、人数を数える → プログラムが得意

この2つを同じ場所でやるから、抜けが出ます。AIには表を組ませて、出来上がった表はCSVへ出し、機械にだけ検査させます。 人が最後に見るのは、機械が出したNGの一覧と、金額や評価が絡む判断だけです。

ステップ1: ルールを数字で書き出す

AIへ渡す前に、次を数字の形にしておきます。ここが曖昧なままだと、AIは「だいたい妥当そうな表」を作り、検査もできません。

  1. 営業時間と、時間帯ごとの必要人数（例: 開店帯2人、昼帯3人、閉店帯2人）
  2. 1日の実働時間の上限（例: 8時間）
  3. 休憩の付け方（実働6時間超で45分、8時間超で60分。労働基準法34条）
  4. 勤務終了から次の勤務開始までの最低間隔（例: 11時間。これは法律上は努力義務なので、自社で何時間にするか決める）
  5. 連勤の上限（例: 6日。法定は週1日以上の休日なので、これも自社ルールとして決める）
  6. 一人で店を回せる人、レジ締めができる人などのスキル区分
  7. 確定している希望休

3〜5は、法令で決まっている部分と自社ルールの部分が混ざります。どちらなのかを分けて書いておくと、あとで「なぜこの数字なのか」を説明できます。

ステップ2: AIでシフトの下書きを作る

条件がそろったら、次のプロンプトで下書きを作ります。出力をCSVに固定しておくのがポイントです。表の形で出させると、そのあと検査へ渡せません。

以下の条件でシフトの下書きを作ってください。

# 期間
2026-09-01 〜 2026-09-07

# 必要人数（時間帯ごと）
- 09:00-12:00 2人
- 12:00-17:00 3人
- 17:00-22:00 2人

# メンバーと制約
- 佐藤: フルタイム、レジ締め可
- 鈴木: フルタイム、レジ締め不可
- 高橋: フルタイム、レジ締め可
- 田中: 週3日まで、17:00以降のみ

# ルール
- 1日の実働は8時間まで（休憩を除く）
- 実働6時間超で休憩45分、8時間超で60分
- 勤務終了から次の勤務開始まで11時間以上あける
- 連勤は6日まで
- 閉店帯にはレジ締め可の人を1人以上入れる

# 希望休
- 鈴木: 09-04, 09-05
- 高橋: 09-07

# 出力
次の列だけのCSVを出力してください。説明文は書かないでください。
date,staff,start,end,break_min

# 禁止
- 条件にない人を登場させない
- 埋められない枠を勝手に人数を減らして埋めたことにしない
- 埋められない枠がある場合は、CSVの後に「未充足: 日付 時間帯 不足人数」とだけ書く

「埋められないときは埋めたことにするな」は必ず入れてください。入れないと、AIは人数を1人減らした表を作り、それを普通のシフトとして出してきます。

ステップ3: 出てきたCSVをPythonで検査する

下書きを shift.csv として保存し、次のコードを実行します。標準ライブラリだけで動きます。

import csv
from collections import defaultdict
from datetime import datetime, timedelta

REQUIRED = {"open": 2, "mid": 3, "close": 2}  # 時間帯ごとの必要人数
SLOTS = {"open": ("09:00", "12:00"), "mid": ("12:00", "17:00"), "close": ("17:00", "22:00")}


def parse(row):
    d = row["date"]
    s = datetime.strptime(f"{d} {row['start']}", "%Y-%m-%d %H:%M")
    e = datetime.strptime(f"{d} {row['end']}", "%Y-%m-%d %H:%M")
    if e <= s:
        e += timedelta(days=1)
    return s, e, int(row["break_min"])


def check(path):
    rows = list(csv.DictReader(open(path, encoding="utf-8")))
    ng = []
    by_staff = defaultdict(list)

    for r in rows:
        s, e, br = parse(r)
        work = (e - s).total_seconds() / 60 - br
        by_staff[r["staff"]].append((s, e, r["date"]))

        if work > 8 * 60:
            ng.append(f"{r['date']} {r['staff']}: 実働 {work/60:.1f}h が8時間を超える")
        need = 60 if work > 8 * 60 else (45 if work > 6 * 60 else 0)
        if br < need:
            ng.append(f"{r['date']} {r['staff']}: 休憩 {br}分 < 必要 {need}分（実働 {work/60:.1f}h）")

    for staff, shifts in by_staff.items():
        shifts.sort()
        for (s1, e1, d1), (s2, e2, d2) in zip(shifts, shifts[1:]):
            gap = (s2 - e1).total_seconds() / 3600
            if gap < 11:
                ng.append(f"{d1}→{d2} {staff}: 勤務間インターバル {gap:.1f}h < 11h")
        days = sorted({datetime.strptime(d, "%Y-%m-%d") for _, _, d in shifts})
        run = 1
        for a, b in zip(days, days[1:]):
            run = run + 1 if (b - a).days == 1 else 1
            if run > 6:
                ng.append(f"{b:%Y-%m-%d} {staff}: 連勤 {run}日目（6日を超える）")

    by_date = defaultdict(list)
    for r in rows:
        by_date[r["date"]].append(parse(r))
    for date, shifts in sorted(by_date.items()):
        for name, (fs, fe) in SLOTS.items():
            f_s = datetime.strptime(f"{date} {fs}", "%Y-%m-%d %H:%M")
            f_e = datetime.strptime(f"{date} {fe}", "%Y-%m-%d %H:%M")
            n = sum(1 for s, e, _ in shifts if s < f_e and e > f_s)
            if n < REQUIRED[name]:
                ng.append(f"{date} {name}帯: 出勤 {n}人 < 必要 {REQUIRED[name]}人")

    print("シフト検査: NG" if ng else "シフト検査: OK（エラー0件）")
    for line in ng:
        print("-", line)


check("shift.csv")

ステップ4: NGをAIへ返して組み直す

検査結果をそのままAIへ戻します。人が直すより速く、直した結果はまた機械で検査できます。

先ほどのCSVを、次の検査結果を解消するように組み直してください。

（ここに検査結果を貼る）

# 条件
- 元の希望休は変更しない
- 解消できない不足がある場合は、無理に埋めず「未充足: 日付 時間帯 不足人数」と書く
- 出力は前回と同じ列のCSVのみ

「解消できないなら埋めるな」を毎回入れてください。これを外すと、AIは休憩を勝手に15分足したり、勤務を1時間削ったりして、検査だけ通る表を作ります。検査が通ることと、店が回ることは別です。

AIに任せてはいけないところ

人の組み合わせ

「この2人だけの日は避けたい」「新人は1人にしない」といった判断は、条件として言語化されないまま現場に存在します。AIは書かれていない条件を守れません。書けるものは条件へ、書けないものは人が最後に見るという切り分けにします。

法令の解釈

この記事のコードが見ているのは、自分で書いた数字を満たしているかだけです。変形労働時間制、みなし労働、36協定の上限、割増賃金の計算などは含まれていません。実際の運用では、社内の就業規則と、必要なら社会保険労務士の確認を通してください。

確定版の配布

検査OKの表を、そのまま「確定」として配らないでください。希望休の反映漏れは、機械では検出できません（希望休の一覧を検査へ渡していないためです）。配る前に本人へ確認する工程を1つ残します。

まとめ

  • シフト作成は「並べる」と「検査する」に分け、検査は必ず機械へ渡す
  • ルールは数字で書き、法令の部分と自社ルールの部分を分けて記録する
  • AIの出力はCSVに固定する。表の形で出させると検査へ渡せない
  • 休憩、実働上限、勤務間インターバル、連勤、時間帯の人数をPythonで検査する
  • 「埋められないなら埋めるな」をプロンプトに毎回入れる
  • 希望休の反映と人の組み合わせは、最後に人が確認する

まずは1週間ぶんだけ、この形で回してみてください。検査を通した週と、目視で作った週で、当日の急な差し替えがどれだけ減るかが分かります。
