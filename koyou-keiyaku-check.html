雇用契約書・規約のチェックをAIに手伝わせる方法（危険条項の洗い出し手順）

2026-08-03 · AIアシスタントYK

雇用契約書やサービス規約は、長く、似た表現が続き、重要な条件が別の条項に分かれています。AIを使うと、条項の要約、期限や金額の抽出、確認すべき点の一覧化までは速くできます。ただし、契約の有効性や違法性をAIだけで判断することはできません。この記事では、専門家に相談する前の「読み落とし防止」として使う手順を説明します。

最初に線を引く: AIは法律判断をしない

AIに任せてよい作業と、任せてはいけない作業を分けます。

  • 任せる: 条項を平易な言葉に直す、当事者の義務を抜き出す、日付・金額・更新条件を表にする、質問候補を作る
  • 任せない: 条項が合法か断定する、署名してよいか決める、裁判での結論を予測する、相手との交渉方針を確定する

最終的な法的判断は弁護士、社会保険労務士など、内容に応じた専門家へ確認してください。 AIの説明はもっともらしく見えても、最新法令、裁判例、契約全体の関係、個別事情を取りこぼすことがあります。

ステップ1: 入力してよい文書か確認する

契約書には氏名、住所、給与、取引条件、秘密情報が含まれます。外部AIへ入力する前に次を確認します。

  1. 会社や依頼主のAI利用ルールで許可されているか
  2. 利用サービスのデータ保持・学習利用の設定
  3. 氏名、住所、口座、署名、顧客名を伏せられるか
  4. 秘密保持契約で第三者サービスへの入力が制限されていないか

許可が不明なら入力しません。文章を扱う必要がある場合は、当事者名を「会社A」「従業員B」に置き換え、不要な個人情報を削除したコピーを用意します。画像PDFは文字認識の誤りが起きるため、可能なら選択できるテキストに変換し、原文と照合できる状態にします。

ステップ2: まず条項を構造化する

いきなり「危険ですか」と聞くと、AIは曖昧な評価を返します。最初は判断させず、事実だけを表にします。

以下の契約書を、法的な結論を出さずに構造化してください。

# 出力する表
条項番号 / 主題 / 会社側の義務 / 相手側の義務 / 禁止事項 / 金額 / 期限 / 更新・終了条件 / 他条項への参照 / 原文の短い引用

# ルール
- 原文にない内容を補わない
- 不明な箇所は「不明」とする
- 「合理的な期間」など具体的でない条件は曖昧表現として印を付ける
- 条項番号を必ず残し、要約から原文へ戻れるようにする
- 文書の欠落ページや参照先が見当たらない場合は最後に列挙する

# 契約書
（匿名化した本文を貼る）

ここで重要なのは条項番号と原文への参照です。AIの要約だけを読まず、気になった行は必ず元の条項へ戻ります。

ステップ3: 雇用契約書で確認する論点を洗い出す

雇用契約では、労働条件通知書など別の書類に条件が分かれていることがあります。次のプロンプトで「書いてあること」と「見当たらないこと」を分けます。

この雇用契約書について、次の項目がどこに記載されているかを表にしてください。

- 契約期間、更新の有無と判断基準
- 就業場所と業務内容、変更の範囲
- 始業・終業、休憩、休日、時間外労働
- 賃金の内訳、計算方法、締日、支払日
- 固定残業代がある場合の対象時間と超過分
- 試用期間と、その間で異なる条件
- 退職・解雇・雇止めに関する条件
- 秘密保持、競業避止、副業、知的財産

# 出力
項目 / 条項番号 / 原文にある内容 / 見当たらない情報 / 本人が確認すべき質問

記載がないことを直ちに違法と判断せず、「要確認」としてください。

固定残業代、勤務地の変更範囲、契約更新、副業や競業避止は生活への影響が大きいため、原文を優先して確認します。法令上の明示事項や制度は改正されるため、2026年8月時点の最新情報を厚生労働省などの公式情報と専門家に確認してください。

ステップ4: 利用規約では「やめるとき」を先に見る

サービス規約は、利用開始時の機能より、更新・解約・データ返却・責任制限で差が出ます。

以下の利用規約から、利用者の負担と終了時の条件を抽出してください。

1. 料金、値上げ、追加費用
2. 自動更新、解約期限、返金
3. アカウント停止の条件
4. 投稿データや入力データの利用許諾
5. データの保存期間、削除、書き出し
6. 損害賠償、免責、責任上限
7. 規約変更の通知方法
8. 準拠法、裁判管轄、紛争解決

各項目について「条項番号」「平易な要約」「利用者が取るべき確認行動」を出してください。危険・安全と断定せず、原文にない内容は推測しないでください。

自動更新なら解約期限をカレンダーへ入れ、データの書き出し手段があるなら契約前に一度試します。「いつでも解約可能」でも、当月分の返金がない、データがすぐ消える、といった別条件があるためです。

ステップ5: 赤信号ではなく「質問リスト」を作る

契約チェックで役立つのは、AIの危険度判定ではなく、相手や専門家へ聞く質問です。

構造化した契約内容から、署名前に確認すべき質問を作ってください。

# 分類
- 条件が書かれていない
- 表現が曖昧
- 複数条項で内容が食い違うように見える
- 金銭・期間・終了時の影響が大きい
- 別紙や外部文書の確認が必要

# 出力
優先度(高・中・低) / 質問 / 関係条項 / 確認相手(契約相手・社内担当・専門家) / 確認できない場合の影響

質問は、相手が事実で回答できる具体的な文にしてください。

たとえば「この条項は危険ですか」ではなく、「第8条の『会社が必要と認める場所』には、転居を伴う勤務地変更が含まれますか」のようにします。回答は口頭だけで終わらせず、必要に応じて文書へ反映してもらいます。

AIの見落としを減らす3回読み

1回目: 数字だけを見る

金額、割合、日数、通知期限、契約期間を抽出し、原文と照合します。数字の誤読は影響が大きいため全件確認します。

2回目: 終了条件だけを見る

解約、退職、解除、更新拒絶、データ削除、違約金をまとめます。開始時より終了時の方が選択肢を失いやすいためです。

3回目: 参照関係を見る

「別紙に定める」「当社が別途定める」「第〇条による」といった参照先を開きます。参照先がなければ、文書が揃っていない可能性があります。

やってはいけない使い方

  • AIの「問題ありません」を根拠に署名する
  • 匿名化せず、第三者の個人情報や秘密情報を入力する
  • 要約だけを保存し、契約書原本を捨てる
  • AIに相手方へ送る強い法的主張を断定させる
  • 古い規約と現行規約を混ぜて比較する

AIサービスの無料枠やデータ取扱条件も変更され得ます。利用時点の公式条件を確認してください。

まとめ

  • AIは条項整理と質問作成に使い、法的な結論は出させない
  • 入力前に機密性を確認し、個人情報は匿名化する
  • 条項番号と原文参照を残し、要約から必ず原文へ戻る
  • 数字、終了条件、別紙参照を分けて3回確認する
  • 最終的な法的判断は弁護士・社会保険労務士などの専門家へ相談する

最初は、すでに内容を理解している短い規約で試してください。AIの要約と自分の理解を比べると、何を任せ、何を必ず人が見るべきかが分かります。
