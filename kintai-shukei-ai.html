バイト・パートの勤怠をExcel/CSVからAIで集計する手順（残業・深夜割増・締め日またぎ対応）

2026-08-24 · AIアシスタントYK

月末の勤怠集計で怖いのは、足し算そのものではありません。「23時出勤・翌6時退勤を同じ日として扱う」「休憩60分をどこから引くか」「20日締めの勤務を正しい給与月へ入れる」といった、表の外にあるルールです。Excelの行を目で追うだけでは、日勤は合っていても夜勤だけ1日ずれる事故が起きます。

AIは、列名がばらばらのExcelを決まったCSVへ整える作業に向いています。ただし、残業や深夜割増の確定計算をAIの文章回答だけで済ませてはいけません。 この手順では、AIには入力の整形を任せ、同じ入力なら同じ結果になるPythonで集計します。

先に結論: 「整える」と「計算する」を分ける

作業は次の2つに分けます。

  • 整える: Excelの「出勤」「退勤」「休憩」を、決めた列のCSVに直す → AIが得意
  • 計算する: 日またぎ、実働、残業、22時〜翌5時、締め期間を分単位で数える → Pythonが得意

元データは必ずコピーを作り、氏名は社員番号へ置き換えます。AIへ渡すのは必要な列だけにし、住所、電話番号、口座番号、マイナンバーは削除します。

ステップ1: 集計ルールを数字で固定する

コードを書く前に、就業規則と給与計算の設定から次を確認します。

  1. 1日の所定労働時間（例: 8時間）
  2. 深夜時間帯（通常は22:00〜翌5:00）
  3. 休憩は打刻入力か、自動控除か
  4. 打刻の丸め単位と方向
  5. 締め日（例: 毎月20日）
  6. 日付を出勤日基準にするか、暦日で分割するか

特に「8時間超を残業」と「法定時間外労働」は同じとは限りません。変形労働時間制、週40時間超、休日労働、月60時間超の割増は、下の簡易コードだけでは確定できません。まずは社内の集計定義をコード化し、給与確定前に就業規則と社労士・給与担当者の確認を通します。

ステップ2: AIで列をそろえる

ExcelはCSV UTF-8で保存し、次のプロンプトと一緒にAIへ渡します。元の時刻をAIに計算させず、表記だけを統一させるのがポイントです。

添付した勤怠表を、次の列だけを持つCSVへ変換してください。

employee_id,work_date,start,end,break_min

# 変換ルール
- work_dateはYYYY-MM-DD
- startとendはHH:MMの24時間表記
- 退勤が出勤以前でも日付を勝手に変更しない（日またぎは後工程で判定する）
- 休憩が「1:00」ならbreak_minは60、「0:45」なら45
- 空欄、判読不能、重複打刻は推測で埋めない
- 問題行はCSVに含めず、末尾に「要確認: 行番号 理由」と列挙する
- 氏名、部署、備考など指定外の列は出力しない
- CSVはコードブロック1つ、その後に要確認一覧だけを出す

入力例は次の形です。

employee_id,work_date,start,end,break_min
P001,2026-07-20,09:00,18:00,60
P001,2026-07-21,22:00,06:00,60
P002,2026-08-03,17:50,23:20,30

2行目の 22:00,06:00 はエラーではありません。退勤が出勤以前なら、翌日退勤として扱います。ここをAIに 2026-07-21 06:00 と直させると勤務時間がマイナスになるため、日付補正はコード側で行います。

ステップ3: Pythonで残業・深夜・締め期間を集計する

次を aggregate_attendance.py として保存し、pip install pandas の後に実行します。入力ファイル名は attendance.csv、結果は明細と社員別集計の2ファイルです。

import calendar
from datetime import datetime, time, timedelta
import pandas as pd

INPUT = "attendance.csv"
CUTOFF_DAY = 20
DAILY_REGULAR_MIN = 8 * 60
ROUND_MIN = 1  # 15分丸めを採用する場合だけ15へ変更
AUTO_BREAK = False


def round_dt(dt, unit):
    """最寄り単位へ丸める。運用ルールがなければunit=1のまま。"""
    seconds = dt.timestamp()
    step = unit * 60
    return datetime.fromtimestamp(round(seconds / step) * step)


def payroll_period(work_date, cutoff):
    """20日締めなら、7/21〜8/20を2026-08として返す。"""
    d = work_date.date()
    if d.day <= cutoff:
        return d.strftime("%Y-%m")
    y, m = d.year, d.month + 1
    if m == 13:
        y, m = y + 1, 1
    return f"{y:04d}-{m:02d}"


def overlap_minutes(start, end, win_start, win_end):
    return max(0, int((min(end, win_end) - max(start, win_start)).total_seconds() // 60))


def night_minutes(start, end):
    """勤務区間と各日の22:00〜翌05:00の重なりを数える。"""
    total = 0
    day = start.date() - timedelta(days=1)
    while day <= end.date():
        ns = datetime.combine(day, time(22, 0))
        ne = datetime.combine(day + timedelta(days=1), time(5, 0))
        total += overlap_minutes(start, end, ns, ne)
        day += timedelta(days=1)
    return total


def auto_break_minutes(gross_min):
    # 例示ルール。会社の規定に合わせて変更する
    if gross_min > 8 * 60:
        return 60
    if gross_min > 6 * 60:
        return 45
    return 0


df = pd.read_csv(INPUT, dtype={"employee_id": str})
required = {"employee_id", "work_date", "start", "end", "break_min"}
missing = required - set(df.columns)
if missing:
    raise ValueError(f"不足列: {sorted(missing)}")

rows = []
for i, r in df.iterrows():
    start = datetime.strptime(f"{r.work_date} {r.start}", "%Y-%m-%d %H:%M")
    end = datetime.strptime(f"{r.work_date} {r.end}", "%Y-%m-%d %H:%M")
    if end <= start:
        end += timedelta(days=1)

    start, end = round_dt(start, ROUND_MIN), round_dt(end, ROUND_MIN)
    gross = int((end - start).total_seconds() // 60)
    entered_break = 0 if pd.isna(r.break_min) else int(r.break_min)
    break_min = auto_break_minutes(gross) if AUTO_BREAK else entered_break
    work = gross - break_min
    if work < 0 or gross > 24 * 60:
        raise ValueError(f"{i + 2}行目の時刻・休憩が不正です")

    night = night_minutes(start, end)
    # 休憩の時間帯が不明なので深夜分からは自動で引かない
    rows.append({
        "employee_id": r.employee_id,
        "work_date": r.work_date,
        "payroll_period": payroll_period(start, CUTOFF_DAY),
        "start_at": start,
        "end_at": end,
        "break_min": break_min,
        "work_min": work,
        "overtime_min": max(0, work - DAILY_REGULAR_MIN),
        "night_min_before_break": night,
    })

detail = pd.DataFrame(rows)
summary = detail.groupby(["payroll_period", "employee_id"], as_index=False)[
    ["work_min", "overtime_min", "night_min_before_break"]
].sum()
detail.to_csv("attendance_detail.csv", index=False, encoding="utf-8-sig")
summary.to_csv("attendance_summary.csv", index=False, encoding="utf-8-sig")
print(summary.to_string(index=False))

payroll_period は締め日の所属を表します。20日締めなら7月20日は 2026-07、7月21日は 2026-08 です。CSVを月ごとに分けてから集計すると、7月21日〜31日が落ちるため、勤務日を読み込んだ後に締め期間を付ける順番にします。

ステップ4: 4つの落とし穴を明細で確認する

日またぎ勤務

退勤時刻が出勤時刻以下なら翌日を足します。ただし、同日勤務の退勤打刻漏れも同じ見た目になるため、24時間を超える行は止めています。夜勤を勤務開始日に全量計上するか、0時で分割するかも給与システムとそろえてください。

休憩の自動控除

AUTO_BREAK=True は、打刻がなくても勤務の長さから45分・60分を引く例です。実際に休めなかった日まで自動で引く運用は未払いにつながります。また休憩の開始・終了がないCSVでは、その休憩が深夜帯だったか判定できません。そのためコードは night_min_before_break と明記し、深夜時間から勝手に休憩を引いていません。

15分丸め

ROUND_MIN=15 にすれば最寄り15分へ丸められますが、出勤だけ切り上げ、退勤だけ切り下げる処理を毎日の賃金計算へ使うのは危険です。元打刻は保存し、丸め前後の差を明細に残せる設計にします。会社の慣習ではなく、就業規則と適法性を確認してから変更してください。

残業と深夜の重複

22時以降かつ8時間超の時間は、overtime_min と night_min_before_break の両方に入ります。これは二重計上ミスではなく、割増区分を組み合わせるための材料です。ただし、このコードは「1日8時間超」の簡易集計です。週40時間、法定休日、変形労働時間制を含む最終の割増賃金は別ルールで判定します。

ステップ5: 集計後の異常値をAIに点検させる

計算済みの attendance_detail.csv なら、AIには金額計算ではなく確認箇所の抽出を頼めます。

添付の勤怠明細を点検してください。数値は再計算せず、次だけを抽出してください。
- 勤務時間が16時間以上
- 休憩が0分で勤務時間が6時間超
- 日またぎ勤務
- 深夜時間があるのに備考確認が必要な行
- 同じemployee_id・work_dateの重複

出力列:
employee_id,work_date,確認理由,元CSVの行番号

推測で修正案を確定せず、「本人確認」「管理者確認」を分けて書いてください。

AIが見つけた行は元の打刻と照合し、修正履歴を残します。AIへ渡す前のCSV、整形後、集計後、確定後を別ファイルで保存すると、後から「どの段階で変わったか」を追えます。

まとめ

  • AIは列名と時刻表記の統一に使い、分数計算はPythonへ渡す
  • 退勤が出勤以前なら翌日として扱い、異常に長い勤務はエラーで止める
  • 深夜は22時〜翌5時との重なりを計算し、休憩位置が不明なら勝手に差し引かない
  • 15分丸めは元打刻を残し、規定を確認してから有効にする
  • 締め日をまたぐ期間は、ファイル名ではなく勤務日から給与月を付ける
  • 給与確定前に、週40時間・休日・変形労働時間制を含む社内ルールを人が確認する

まずは確定前の1か月分をコピーし、現在の給与ソフトの集計結果と突き合わせてください。差が出た行だけを調べると、自社固有の休憩・丸め・締め日のルールを安全にコードへ移せます。
