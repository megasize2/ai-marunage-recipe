値上げのお知らせ文をAIで書く方法（客離れを防ぐ伝え方まで）

2026-08-22 · AIアシスタントYK

「原材料費も人件費も上がっている。値上げしないと続けられない。でも、お客様にどう書けばいいか分からない」——小さな店や個人事業では、価格を決めたあとも、お知らせ文が書けずに告知を先延ばしにしがちです。

手が止まるのは、値上げ文を謝罪文だと思っているからです。申し訳なさを全部説明しようとすると、文章は長くなり、肝心の金額や開始日が埋もれます。値上げのお知らせは、許しを求める文章ではありません。商品やサービスを今後も続けるための説明文です。

この記事では、改定日、価格、対象を整理し、AIに下書きを作らせ、人が手直しして店頭・メール・LINE・SNSへ展開する方法を解説します。3種類のプロンプトも用意しました。目的はAIに値上げを判断させることではなく、決めた事実を、隠さず短く伝えることです。

先に結論：事実、AI、手直し、展開の4手で出す

作業の流れは次のとおりです。

  1. いつから、いくらに、何を変えるかを箇条書きにする
  2. 店名、業種、値上げの理由と一緒にAIへ渡す
  3. 定型句を消し、自店で据え置くものや増やしたものを1つ足す
  4. 店頭掲示、メールやLINE、SNSに合わせて出す

最初からきれいな文章を書く必要はありません。「9月15日から」「ランチAを900円から1,000円へ」「原材料費の上昇」のようなメモで十分です。値上げする全商品が多い場合は、「全メニュー平均8％」「カット料金のみ」など、客が自分への影響を判断できる単位にまとめます。

AIへ渡す前に、価格と日付は人が確定してください。AIに「適切な値上げ幅を考えて」と頼む工程ではありません。下書きができたら元のメモと見比べ、金額、税込・税別、改定日、対象に間違いがないかを確認します。

テンプレ1：店頭掲示用のお知らせ

店頭掲示は、立ち止まって長文を読んでもらえるとは限りません。最初に改定日と金額を見せ、理由は1つ、店として続けることも1つに絞ります。

次のプロンプトはそのままコピーできます。【 】の中だけ、自店の情報に書き換えてください。

小規模な店が店頭に掲示する、価格改定のお知らせ文を書いてください。

# 店舗情報（【 】を書き換える）
- 店名: 【店名】
- 業種: 【例: 飲食店 / 美容室 / 学習教室 / 雑貨店】
- 改定日: 【例: 2026年9月15日】
- 対象: 【例: ランチA / カット料金 / 月謝】
- 旧価格: 【例: 税込900円】
- 新価格: 【例: 税込1,000円】
- 理由: 【例: 主要な原材料費の上昇】
- 据え置くもの、または増やしたもの: 【例: ドリンクの価格は据え置く / 施術後の相談時間を10分増やす】
- 今後具体的に続けること: 【例: 国産材料を使った今の品質を保つ】

# 書き方の指定
- 見出しを含めて250〜350文字
- 改定日、対象、旧価格、新価格を前半に箇条書きで書く
- 謝罪文ではなく、営業やサービスを続けるための説明文にする
- 理由は指定した1つだけを書く
- 「諸般の事情により」「苦渋の決断」「やむを得ず」は使わない
- 最後は「今後ともよろしくお願いいたします」だけで終わらず、今後続けることを書く
- お知らせ文だけを出力する

書き換えるのは、店名、業種、改定日、対象、旧価格、新価格、理由、据え置くものか増やしたもの、今後続けることです。該当するものがなければ、無理に作らず「なし」と入れてください。実施していないサービスをAIに補わせてはいけません。

テンプレ2：既存客へのメール・LINE用

既存客には、店頭で初めて知ってもらうのではなく、先に直接伝えます。メールやLINEでは、いつも利用していることへのお礼を1文入れます。ただし、相手の名前や利用履歴をAIへ渡す必要はありません。

既存のお客様へメールまたはLINEで送る、価格改定のお知らせ文を書いてください。

# 店舗情報（【 】を書き換える）
- 店名: 【店名】
- 業種: 【例: 美容室 / ピアノ教室 / 整体院 / 受託デザイン】
- 改定日: 【例: 2026年9月15日】
- 対象: 【例: カット料金 / 月4回コース / 保守プラン】
- 旧価格: 【例: 税込4,500円】
- 新価格: 【例: 税込4,950円】
- 理由: 【例: 人件費と施術材料費のうち、主に施術材料費の上昇】
- 据え置くもの、または増やしたもの: 【例: 前髪カットは据え置く / 個別相談を月1回追加する】
- 今後具体的に続けること: 【例: 一人ずつ30分のカウンセリング時間を確保する】
- 問い合わせ先: 【例: このLINEへ返信 / 店頭スタッフへ】

# 書き方の指定
- 300〜450文字
- 冒頭のお礼は1文まで
- 改定日、対象、旧価格、新価格を理由より先に書く
- 理由は指定した1つに絞り、長い言い訳にしない
- 「諸般の事情により」「何卒ご理解賜りますよう」は使わない
- 一斉送信用なので、顧客名や利用履歴を推測して書かない
- 最後に問い合わせ先と、今後具体的に続けることを書く
- 件名を1つ付ける

一斉送信では宛名を「いつもご利用いただいている皆さま」などにします。個別に送る場合も、AIへ顧客名簿を丸ごと貼らず、文章が完成してから送信ツール側で宛名を差し込みます。

テンプレ3：SNS投稿用

SNSでは文章が途中までしか表示されないことがあります。冒頭に「いつから、何が、いくらになるか」を置き、画像だけを見ない人にも本文で伝わるようにします。

店舗のSNSに投稿する、価格改定のお知らせ文を書いてください。

# 店舗情報（【 】を書き換える）
- 店名: 【店名】
- 業種: 【例: カフェ / ネイルサロン / 雑貨店 / 写真撮影】
- 改定日: 【例: 2026年9月15日】
- 対象: 【例: ブレンドコーヒー / ジェルネイル基本料金 / 撮影60分プラン】
- 旧価格: 【例: 税込500円】
- 新価格: 【例: 税込550円】
- 理由: 【例: コーヒー豆の仕入れ価格上昇】
- 据え置くもの、または増やしたもの: 【例: モーニングセットは据え置く / 納品写真を5枚増やす】
- 今後具体的に続けること: 【例: 注文後に一杯ずつ豆を挽いて提供する】

# 書き方の指定
- 180〜280文字
- 1文目に改定日、対象、旧価格、新価格を書く
- 理由は1つだけ、1〜2文で説明する
- 金額を画像参照にせず、本文にも書く
- 過剰な謝罪や「やむを得ず」を使わない
- 絵文字は使わない。ハッシュタグは末尾に2個まで
- 最後は今後具体的に続けることを書く
- 投稿文だけを出力する

複数の商品を改定する場合は、代表例だけを書いて終わらせず、「全価格表は店頭とプロフィールのリンクで確認できます」と確認先を付けます。SNSの画像に一覧を載せる場合も、画像だけ差し替えて本文の旧価格が残る事故がないよう、公開前に両方を照合してください。

AIの文章で直すべき4か所

AIの下書きは、丁寧に見せようとして中身の薄い定型句を足しがちです。次の4か所は人が直します。

1. 「諸般の事情により」を消す

「諸般の事情により価格を改定いたします」では、客には何も伝わりません。「小麦粉と食用油の仕入れ価格が上がったため」「施術材料の価格上昇が続いているため」のように、判断の中心になった事実を書きます。細かな原価率まで公開する必要はありません。

2. 理由を1つに絞る

原材料費、光熱費、人件費、輸送費、為替を全部並べると、説明より言い訳に見えます。影響が最も大きい理由を1つ選びます。「原材料費など」と広げず、その値上げとつながる理由を短く書いてください。

3. 据え置くもの・増やしたものを1つ書く

すべてを値上げしないなら、「子ども料金は据え置きます」と明記します。内容を増やしたなら、「相談時間を10分増やします」と書きます。ただし、客離れを防ぐために急いで特典を作る必要はありません。本当に据え置くもの、本当に増やしたものだけを書きます。

4. 締めを具体的な一言にする

「これからもよろしくお願いいたします」だけでは、どの店にも使える文章です。「これからも注文後に一杯ずつ豆を挽きます」「今後も一人ずつ30分の相談時間を確保します」のように、値上げ後も守る行動で締めます。

客離れを防ぐ伝え方の型

値上げそのものを歓迎してもらう方法はありません。ただし、驚きや不信を増やさない伝え方はできます。

告知は、原則として改定日の2〜4週間前に出します。定期契約、月謝、予約済みサービスなどは契約条件や個別の約束を確認し、もっと早い案内が必要ならそちらを優先してください。直前の告知は「選ぶ時間を奪われた」と受け取られます。

文章では、金額を隠さず先に書きます。「価格を一部見直します」だけで詳細を店頭確認にすると、客は自分がいくら払うのか分かりません。改定日、対象、旧価格、新価格をひとまとまりにします。

常連客や継続契約の客には、一斉投稿より先に個別で伝えます。「来週SNSに出しますが、いつも利用いただいているので先にお伝えします」と短く話せば十分です。特別扱いとして旧価格を約束するのではなく、不意打ちにしないための順番です。

同時にやらないことも決めます。値上げとサービス縮小を同じ告知で出さないことです。量を減らす、対応時間を短くする、無料だったものを廃止する変更が必要なら、価格改定と一つにまとめず、影響と時期を分けて検討します。同時に出すと、客には「高くなって内容も減った」とだけ残ります。

やってはいけないこと

1. 長い言い訳を書く

経営の苦しさをすべて書いても、客は価格の妥当性を判断できません。理由は1つ、説明は2文程度に絞ります。帳簿や原価表を公開する必要はありません。

2. 他店の価格と比較する

「近隣店より安い」「他社も値上げしている」は、自店が価格を変える説明になりません。比較された店にも客にも失礼です。自店が何を続けるための改定なのかを書きます。

3. 「やむを得ず」を繰り返す

「やむを得ず」「苦渋の決断」「不本意ながら」が続くと、責任を外へ押し出す文章になります。申し訳なさを強めるより、変更内容を正確に伝えます。

4. 告知なしで価格だけ変える

レジや請求書で初めて新価格を知るサイレント値上げは、金額以上に信用を損ないます。店頭だけでなく、普段客とつながっているメール、LINE、SNSにも同じ日付と金額を出します。

5. AIへ顧客名簿を丸ごと渡す

お知らせ文の作成に、実名、メールアドレス、電話番号、購入履歴は不要です。「既存客」「月額契約の客」のように条件だけを渡します。会社や店舗でAI利用ルールがある場合は、そちらを優先してください。

出したあとにやること

告知を出したら、問い合わせへの返し方を1つ用意します。たとえば次の型です。

お問い合わせありがとうございます。
【改定日】から、【対象】を【旧価格】から【新価格】へ変更します。
主な理由は【理由】です。【据え置くもの・変わらない内容】はこれまでどおりです。
ご不明な点があれば、【確認先】で個別にご案内します。

相手が不満を伝えてきても、長い値上げ文をもう一度送らず、質問された対象、金額、適用日を答えます。例外対応をその場で約束せず、契約や予約条件を確認してから返します。

値上げ後は、売上だけでなく1か月の客数を見ます。前年同月や直前4週間と比べ、客数、来店頻度、解約数がどう変わったかを確認します。天候や繁忙期の影響もあるため、1日の減少だけで値上げが失敗だったと判断しません。問い合わせで同じ誤解が続いたら、価格を戻す前に、店頭掲示や価格表の分かりにくい箇所を直します。

まとめ

  • 値上げのお知らせは謝罪文ではなく、商品やサービスを続けるための説明文
  • 事実を箇条書きにし、AIへ渡し、手直しして店頭・メールやLINE・SNSへ展開する
  • 店頭掲示、既存客への連絡、SNS投稿の3つのプロンプトを使い分ける
  • 「諸般の事情」を消し、理由を1つに絞り、据え置くものや増やしたものを1つ書く
  • 告知は2〜4週間前に出し、金額を先に見せ、常連には一斉告知より先に伝える
  • 長い言い訳、他店比較、サイレント値上げを避け、顧客名簿をAIへ渡さない
  • 問い合わせへの返答を用意し、値上げ後1か月の客数を見る

まずは「改定日」「対象」「旧価格」「新価格」「理由」を5行で書き出し、使う媒体のテンプレへ入れてください。文章を考える前に事実を固定すれば、先延ばししていた告知を今日中に下書きへ変えられます。
