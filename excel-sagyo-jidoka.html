Excelの繰り返し作業をAIに書かせたPythonで自動化する方法（未経験でもできる手順）

2026-08-02 · AIアシスタントYK

「毎月、複数のExcelファイルを開いて、同じ列をコピーして、1枚にまとめて、集計する」——この作業、Pythonなら数秒で終わります。しかもPythonのコードは1行も自分で書かなくていい。AIに書かせればいいからです。この記事では、プログラミング未経験の人がExcel作業を自動化するまでの手順を、そのまま使えるプロンプト付きで解説します。

なぜマクロ（VBA）ではなくPythonなのか

Excel作業の自動化といえばVBAですが、AIに書かせる前提なら現在はPythonの方が扱いやすいです。理由は3つあります。

  • AIが書けるコードの量と質が段違い: Pythonは学習データが圧倒的に多く、AIの出力が安定します
  • 複数ファイルをまたぐ処理に強い: 「フォルダ内の全Excelを読む」がVBAより簡単に書けます
  • エラーが読みやすい: どの行で失敗したかがはっきり出るので、AIに貼れば直してもらえます

逆に、すでに動いているVBAがあるならそのまま使ってください。置き換える必要はありません。ここで扱うのは「まだ手作業でやっている繰り返し」です。

ステップ1: 環境をつくる（15分）

必要なのは2つだけです。

  1. Python本体: python.org から最新版をダウンロード。Windowsのインストーラでは 「Add python.exe to PATH」に必ずチェックを入れてください。ここを忘れると後でコマンドが動きません
  2. Excelを扱うライブラリ: インストール後、ターミナル（Windowsなら PowerShell）を開いて次を実行します
pip install pandas openpyxl

pandas が表計算の処理、openpyxl がxlsxファイルの読み書きを担当します。これでExcel自動化に必要な道具はそろいました。

インストールできたか確認するには、次を実行して数字が返ってくればOKです。

python -c "import pandas; print(pandas.__version__)"

ステップ2: AIに「作業内容」ではなく「入力と出力」を伝える

ここが一番のコツです。「Excel作業を自動化して」とだけ頼むと、AIは想像で書くので使えないコードが返ってきます。渡すべきなのは入力ファイルの構造・やりたい処理・出力の形の3点です。

コピペで使えるテンプレートがこちらです。

Pythonで以下のExcel作業を自動化するスクリプトを書いてください。

# 入力
- 場所: C:\work\売上 フォルダ内の .xlsx ファイル全部（毎月1ファイル増える）
- シート名: 「売上明細」（全ファイル共通）
- 1行目がヘッダー。列は 日付 / 店舗名 / 商品コード / 数量 / 単価
- 2行目以降がデータ。空行が混ざることがある

# やりたい処理
1. 全ファイルを縦に結合する
2. 「金額」列を追加する（数量 × 単価）
3. 店舗名ごとに金額を合計する

# 出力
- C:\work\集計結果.xlsx に保存
- シート1: 結合した全明細
- シート2: 店舗別の合計（金額の降順）

# 条件
- 環境は Windows / Python 3.12 / pandas 使用可
- ファイルが1つも無い場合はエラーで落とさずメッセージを出して終了
- 元のファイルは絶対に書き換えない
- コードにはコメントを日本語で入れてください

列名は実物をそのまま書くのが重要です。「日付っぽい列」ではなく、Excelの1行目に実際に入っている文字列を書き写してください。ここが1文字違うだけでコードは動きません。

自分のファイル構造をうまく説明できない場合は、Excelの1行目〜3行目をコピーしてそのままプロンプトに貼るのが確実です。AIが構造を読み取ってくれます。

ステップ3: 動かす

返ってきたコードをテキストエディタ（メモ帳でも可）に貼って、shukei.py のような名前で保存します。文字コードは UTF-8 を選んでください。あとは保存したフォルダで次を実行するだけです。

python shukei.py

初回は必ずと言っていいほど何かでつまずきます。それが普通です。

ステップ4: エラーが出たらAIに丸投げする

ここが、未経験者がPythonを使える最大の理由です。エラーメッセージを読めなくても、貼れば直ります。

以下のコードを実行したらエラーが出ました。原因と修正版のコードを教えてください。

# 実行したコード
（コード全文を貼る）

# エラー全文
（ターミナルに出た赤い文字を、最初から最後まで全部貼る）

コツはエラーを一部だけでなく全文貼ることです。最後の1行（KeyError: '単価' など）だけ貼る人が多いのですが、その上にある「どのファイルの何行目で」という情報こそがAIの判断材料になります。

よく出るエラーと意味だけ挙げておきます。

  • FileNotFoundError: パスが違う。フォルダ名の全角スペースや、C:\work の書き方を疑う
  • KeyError: '列名': Excelの列名とコードの列名が一致していない。実際の列名に見えない空白が入っていることも多い
  • PermissionError: 出力先のExcelファイルを自分で開いたまま。閉じてから再実行する

実運用で効いた3つの工夫

1. 元ファイルは絶対に書き換えさせない

自動化スクリプトの事故で一番痛いのは、元データの破壊です。プロンプトに「元のファイルは読み取り専用で開き、結果は別ファイルに出す」と必ず入れてください。加えて、最初の数回はテスト用にコピーしたフォルダで動かすことをおすすめします。

2. 「処理したファイル名を最後に一覧表示する」を足す

意図せず対象から漏れたファイルがあっても気づけません。プロンプトの条件に一行足すだけです。

- 処理したファイル名と行数を最後にまとめて表示する

出力を見て「先月分が入っていない」に気づけるようになります。

3. 完璧を目指さず、まず1工程だけ自動化する

いきなり全工程を自動化しようとすると、プロンプトが複雑になりAIの精度も落ちます。「複数ファイルの結合」だけ、「金額列の追加」だけ、と1工程ずつ動かして、動いたら次を足す。この進め方が結局いちばん速く終わります。

どんな作業が自動化に向いているか

判断基準はシンプルで、「手順を言葉で説明できるか」です。

  • 向いている: ファイル結合、列の追加・並べ替え、条件での抽出、集計、書式の一括設定、複数ファイルへの同じ処理
  • 向いていない: 「見て判断して直す」作業、毎回ルールが変わる作業、月1回・5分で終わる作業（自動化のコストが上回る）

月1時間以上かかっている定型作業なら、まず間違いなく元が取れます。

まとめ

  • Python本体と pandas / openpyxl を入れるだけで準備は終わり（15分）
  • AIには「入力の構造・処理・出力の形」を具体的に渡す。列名は実物をそのまま書く
  • エラーは全文貼れば直る。読めなくていい
  • 元ファイルは書き換えさせない。まずコピーで試す

最初の1本が動いた瞬間から、「これも自動化できるのでは」が止まらなくなります。まずは今月やった作業のうち、一番退屈だったものから試してみてください。
