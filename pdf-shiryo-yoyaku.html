長いPDF資料をAIに要約させる方法（100ページでも要点と比較表が作れる手順）

2026-08-09 · AIアシスタントYK

「80ページの調査報告書を今日中に読んで、会議で説明してほしい」——こんな仕事は、最初から最後まで順番に読むと半日が消えます。PDFをAIに渡せば短くできますが、ただ「要約して」と頼むだけでは、重要な条件や例外が抜けます。この記事では、長いPDFを分割して読み、要点・根拠・未確認事項を残したまま1枚のメモへまとめる手順を解説します。

先に決める: 何のために読むのか

同じ資料でも、上司への説明、導入判断、競合比較では必要な情報が違います。AIへ渡す前に、次の3点を1行ずつ書きます。

  1. 読む目的: 例「新システムを導入するか判断する」
  2. 知りたい項目: 費用、効果、リスク、開始時期など
  3. 出力の形: 5項目の箇条書き、表、300字の説明文など

この3点がないと、AIは目立つ文章を短くするだけです。目的を先に固定すると、読むべきページと捨ててよいページを分けられます。

ステップ1: PDFが文字として読めるか確認する

まずPDFを開き、本文を数行ドラッグしてコピーします。メモ帳へ貼って正しく読めれば、そのPDFには文字データがあります。コピーできない、貼ると文字化けする場合は、紙をスキャンした画像PDFです。

画像PDFは、Googleドライブへアップロードして「Googleドキュメントで開く」と文字認識できます。原本は残し、変換後の文書を別名で保存してください。表や脚注は崩れやすいため、数字を使う箇所は必ず元PDFのページと見比べます。

会社の機密資料や個人情報を含むPDFは、利用中のAIサービスへ入力してよいか社内ルールを先に確認します。許可がない場合は、社名・氏名・金額などを伏せるか、承認済みの環境だけを使ってください。

ステップ2: 長いPDFは章ごとに分ける

ファイルをそのまま添付できても、100ページを一度に頼むと後半の細部が薄くなりがちです。目次を見て、章または20〜30ページ程度の意味の切れ目で分けます。ページ数を機械的に揃えるより、「調査方法」「結果」「提言」のように話題を切らない方が重要です。

分割できない場合は、PDF閲覧ソフトの印刷画面でページ範囲を指定し、「PDFとして保存」します。ファイル名は 01_概要.pdf、02_調査結果.pdf のように順番が分かる形にします。

各ファイルへ次のプロンプトを使います。

添付したPDFは長い報告書の一部です。推測で補わず、このファイルに書かれている内容だけを整理してください。

# 読む目的
- 新システムを導入するか、部内会議で判断する

# 抽出する項目
1. この章の結論（3点以内）
2. 結論を支える数値・事例と、その掲載ページ
3. 導入の条件・前提
4. リスク、例外、反対意見
5. 次の章と一緒に確認すべき点

# 出力条件
- 各項目を箇条書きにする
- PDFにないことは「記載なし」と書く
- 数値には単位と対象期間を付ける
- 最後に100字以内の章要約を付ける

「ページ番号」「記載なし」「推測しない」の3つを入れると、あとで原文へ戻れます。ページ番号がずれるPDFもあるので、重要な引用は検索して場所を再確認してください。

ステップ3: 章ごとの要約を全体へ統合する

各章の要約ができたら、新しいチャットにまとめて貼ります。元PDFをもう一度全部読ませるのではなく、章要約を材料にして全体像を作ります。

以下は同じ報告書を章ごとに要約したメモです。重複を除き、意思決定用の1枚メモに統合してください。

# 出力
- 全体の結論: 3点
- 重要な数値: 「数値 / 意味 / 元の章・ページ」の表
- 導入する場合の条件: 箇条書き
- リスクと未確認事項: 分けて記載
- 会議で確認する質問: 5問
- 役員向け200字要約

# 条件
- 章同士で数字や主張が矛盾する場合は統合せず、両方を示す
- 原文で確認できない内容を追加しない

（ここに章ごとの要約を順番に貼る）

要約を統合した後、重要な数値を3〜5個選び、元PDFと照合します。全ページを読み直す必要はありません。判断を変えうる数字と例外だけを人が確認するのが現実的です。

複数資料を比較するときは項目を固定する

競合3社の資料や年度別の報告書は、1冊ずつ自由に要約すると比較できません。先に比較軸を決め、同じ表へ入れます。

添付した3つの資料を比較してください。

# 比較軸
- 対象者
- 提供範囲
- 導入条件
- 費用として明記された項目
- 導入期間
- 実績・効果の根拠
- リスクまたは制約

# 出力
- 行を比較軸、列を資料A・資料B・資料Cにした表
- 記載がないセルは「記載なし」
- 各セルの末尾に資料名とページ番号を付ける
- 表の後に「共通点」「相違点」「比較できない点」を分けて書く
- 優劣は決めず、資料から確認できる事実だけを示す

公開年や対象範囲が違う資料は、数字だけを横並びにできません。「比較できない点」を出させることで、もっともらしい誤比較を防げます。

要約で事故を防ぐ3つの確認

1. 数字は単位と母数まで見る

「20%改善」だけでは判断できません。何が、何件を対象に、いつと比べて改善したのかを確認します。単位・期間・母数がない数字は、会議資料にそのまま載せません。

2. 結論より脚注と例外を確認する

対象外条件や調査の限界は、小さな文字に置かれます。AIへ「脚注、但し書き、対象外条件だけを一覧にして」と追加で頼むと、都合のよい要約になるのを防げます。

3. 引用文は原文からコピーする

AIの要約文を引用符で囲むと、原文にない表現を引用したことになります。社外資料へ載せる引用は、ページを開いて原文からコピーしてください。

まとめ

  • PDFを読む前に目的・知りたい項目・出力形式を決める
  • 長い資料は章の意味を切らない範囲で分割し、ページ番号付きで要約する
  • 章要約を統合し、判断を変える数字と例外だけ元PDFで確認する
  • 複数資料は比較軸を固定し、「記載なし」と「比較できない」を残す

最初は1冊を完璧に自動化せず、目次と結論の章だけで試してください。読むべき場所が見えた時点で、資料に費やす時間は大きく減ります。
