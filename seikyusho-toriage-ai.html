取引先ごとに形式が違うExcel請求書をAIで読み取り、支払一覧へまとめる手順

2026-08-25 · AIアシスタントYK

月末に届く請求書は、A社は請求日が右上、B社は明細の下、C社はシート名が「御請求書」と、同じExcelでも置き場所が違います。さらにセル結合や数式が入るため、全ファイルをコピー＆ペーストして1枚にするほど確認箇所が増えます。

AIは、表の意味を読んで共通の列へ置き換える作業に向いています。ただし、AIが返した合計額をそのまま支払確定額にしてはいけません。 この手順では、AIには項目の抽出を任せ、Pythonで必須項目、税率、重複、明細合計を検査してから支払一覧を作ります。

先に結論: 「読み取る」と「確定する」を分ける

作業は次の2つに分けます。

  • 読み取る: 各社のExcelから請求番号、支払期日、明細を共通CSVへ直す → AIが得意
  • 確定する: 金額照合、重複除外、会社別・期日別の一覧化 → Pythonが得意

原本は invoices_original に保存し、AIへ渡すコピーから口座番号、担当者の個人連絡先、不要な社内メモを削除します。利用するAIサービスの契約、学習利用、保存期間も社内ルールに合わせてください。

ステップ1: 支払一覧の列を先に固定する

最初に、全社共通の出力を次の列へ固定します。

  1. source_file: 原本ファイル名
  2. vendor: 取引先名
  3. invoice_no: 請求書番号
  4. invoice_date、due_date: 請求日と支払期日
  5. line_no、description、unit: 明細情報
  6. net_amount、tax_rate、tax_amount: 税抜額、税率、税額
  7. invoice_total: 請求書に印字された税込合計
  8. needs_review: 判読不能や規則外を示す理由

1請求書を1行にせず、まずは明細1行をCSVの1行にします。税率8%と10%が混在しても明細ごとに保持でき、後から税率別に照合できます。一方、invoice_total は各明細へ同じ値を繰り返して構いません。集計時には最初の1件だけを使います。

ステップ2: ExcelをAIが読める形にする

ファイルを開いたら、非表示行・列、数式エラー、複数シートの有無を確認します。AIへExcelを直接添付できない場合は、各シートをPDFかCSVへ書き出します。ただしCSVでは結合セルの左上以外が空欄になるため、見出しの意味が失われる場合はPDFも併用します。

同じ会社でも、経理ソフト更新後に「請求額」がD12からH8へ移ることがあります。セル番地を固定したプロンプトではなく、見出しと周辺の意味から抽出させます。次を請求書1冊ごとに使います。

添付したExcel請求書を読み取り、明細1行につき1行のCSVへ変換してください。

出力列:
source_file,vendor,invoice_no,invoice_date,due_date,line_no,description,unit,net_amount,tax_rate,tax_amount,invoice_total,needs_review

# 変換ルール
- 日付はYYYY-MM-DD、金額はカンマと通貨記号を除いた整数
- 結合セルは左上の値を同じ見出し範囲へ補完して解釈する
- 「小計」「消費税」「合計」「請求金額」は明細として出力しない
- 単位が「式」の行は数量×単価を推測せず、記載済みの金額をnet_amountへ入れる
- 税率8%と10%が混在する場合は明細ごとにtax_rateを入れる
- 税率が空欄なら推測せずneeds_reviewに「税率不明」と書く
- 請求書番号、支払期日、合計額が見つからない場合も空欄のままneeds_reviewへ理由を書く
- 数式セルは表示値を読み、数式文字列そのものは出力しない
- 同じ行を、明細と合計行の両方から二重に出力しない
- CSVコードブロック1つだけを出力する

AIの出力は請求書ごとに normalized フォルダへ保存します。たとえば A社_2026-08.csv のようにし、CSVを上書きせず原本との対応を残します。

ステップ3: Pythonで支払一覧へ統合する

次を merge_invoices.py として保存し、pip install pandas openpyxl の後に実行します。normalized 内のCSVを読み、payment_list.xlsx に支払一覧、税率別集計、要確認の3シートを作ります。

from pathlib import Path
from decimal import Decimal, InvalidOperation, ROUND_HALF_UP
import pandas as pd

INPUT_DIR = Path("normalized")
OUTPUT = "payment_list.xlsx"
KEYS = ["vendor", "invoice_no"]
REQUIRED = {
    "source_file", "vendor", "invoice_no", "invoice_date", "due_date",
    "line_no", "description", "unit", "net_amount", "tax_rate",
    "tax_amount", "invoice_total", "needs_review",
}


def money(value):
    """空欄はNA、金額は1円単位の整数へそろえる。"""
    if pd.isna(value) or str(value).strip() == "":
        return pd.NA
    text = str(value).replace(",", "").replace("¥", "").strip()
    try:
        return int(Decimal(text).quantize(Decimal("1"), rounding=ROUND_HALF_UP))
    except InvalidOperation as exc:
        raise ValueError(f"金額として読めません: {value}") from exc


files = sorted(INPUT_DIR.glob("*.csv"))
if not files:
    raise FileNotFoundError("normalizedフォルダにCSVがありません")

frames = []
for path in files:
    df = pd.read_csv(path, dtype=str).fillna("")
    missing = REQUIRED - set(df.columns)
    if missing:
        raise ValueError(f"{path.name} の不足列: {sorted(missing)}")
    df["input_csv"] = path.name
    frames.append(df)

detail = pd.concat(frames, ignore_index=True)
for col in ["net_amount", "tax_amount", "invoice_total"]:
    detail[col] = detail[col].map(money).astype("Int64")
detail["tax_rate"] = detail["tax_rate"].str.replace("%", "", regex=False)
detail["tax_rate"] = pd.to_numeric(detail["tax_rate"], errors="coerce")
detail["invoice_date"] = pd.to_datetime(detail["invoice_date"], errors="coerce")
detail["due_date"] = pd.to_datetime(detail["due_date"], errors="coerce")

# 同じ会社・同じ番号は同一請求書として扱う。番号なしは必ず要確認へ送る。
blank_no = detail["invoice_no"].eq("")
detail.loc[blank_no, "needs_review"] += " 請求書番号なし"

invoice = detail.groupby(KEYS, dropna=False, as_index=False).agg(
    source_file=("source_file", "first"),
    invoice_date=("invoice_date", "first"),
    due_date=("due_date", "first"),
    line_net=("net_amount", "sum"),
    line_tax=("tax_amount", "sum"),
    invoice_total=("invoice_total", "first"),  # 合計行を明細数だけ足さない
    needs_review=("needs_review", lambda s: " / ".join(x for x in s if x)),
    rows=("line_no", "count"),
)
invoice["calculated_total"] = invoice["line_net"] + invoice["line_tax"]
invoice["difference"] = invoice["invoice_total"] - invoice["calculated_total"]
invoice.loc[invoice["difference"].ne(0), "needs_review"] += " 合計不一致"

# 同一番号が複数CSVに現れたら、自動で1件に確定せず重複候補にする。
sources = detail.groupby(KEYS)["input_csv"].nunique()
duplicate_keys = sources[sources > 1].index
is_duplicate = pd.MultiIndex.from_frame(invoice[KEYS]).isin(duplicate_keys)
invoice.loc[is_duplicate, "needs_review"] += " 重複請求候補"

tax_summary = detail.groupby(KEYS + ["tax_rate"], dropna=False, as_index=False).agg(
    net_amount=("net_amount", "sum"),
    tax_amount=("tax_amount", "sum"),
)
review = invoice[invoice["needs_review"].str.strip().ne("")].copy()

with pd.ExcelWriter(OUTPUT, engine="openpyxl") as writer:
    invoice.sort_values(["due_date", "vendor"]).to_excel(
        writer, sheet_name="支払一覧", index=False
    )
    tax_summary.to_excel(writer, sheet_name="税率別集計", index=False)
    review.to_excel(writer, sheet_name="要確認", index=False)

print(f"{len(invoice)}件を{OUTPUT}へ出力、要確認は{len(review)}件です")

このコードは invoice_total に first を使います。明細が10行ある請求書で、各行に同じ税込合計が入っていても10倍になりません。また「式」の行も net_amount を直接足すため、数量が空欄でも落ちません。

ステップ4: 5つの落とし穴を明細で確認する

結合セル

「品名」がA列とB列の結合、「金額」がF列とG列の結合なら、CSV化すると片方が空欄になります。空欄をすべて上の値で埋めると、今度は小計や備考まで誤補完します。AIには見出し範囲だけを補完させ、出力後は原本の先頭・中央・最終明細を照合します。

税率混在

8%と10%を請求書全体の税率1つへ丸めると、税額差が出ます。明細別の tax_rate を残し、税率別集計 で税抜額と税額を確認します。端数処理が明細単位か税率別合計単位かは取引先ごとに異なるため、差額をAIに推測させません。

単位が「式」の行

保守作業一式のような行は、数量1・単価を補っても結果が合うとは限りません。請求書に記載された行金額を採用し、数量×単価の再現はしません。内訳が必要なら支払確定前に取引先へ確認します。

同じ会社で様式が変わる

セル番地固定のマクロは、列追加だけで別項目を読みます。毎月、請求番号・合計・最初の明細の位置を記録し、前月と位置や見出しが変わったファイルは全件確認へ回します。AIプロンプトも「D12を読む」ではなく項目名で指定します。

合計行の二重計上

明細の末尾に小計、消費税、税込合計が並ぶ表で、すべてを net_amount に入れると二重・三重計上になります。合計行は明細から除外し、印字された invoice_total と、明細税抜＋明細税額を別々に持って差額を出します。

ステップ5: 要確認だけを人が原本と照合する

要確認 シートは、合計不一致、請求番号なし、重複候補、税率不明を優先して確認します。判断結果はCSVを直接上書きせず、「確認者」「確認日」「修正理由」を支払一覧へ追加して残します。

添付した支払一覧の「要確認」行だけを分類してください。
分類は「原本再確認」「取引先へ確認」「重複確認」の3つです。
金額、税率、支払期日は推測で修正しないでください。

出力列:
vendor,invoice_no,分類,確認する箇所,原本ファイル名

AIの分類は確認順を決めるための補助です。銀行振込データへ移す前に、請求書番号、取引先、支払期日、税込合計を人が照合し、重複候補を解消します。

まとめ

  • AIは各社の見出しを共通CSVへ変換し、金額確定はPythonと人の照合へ渡す
  • 結合セルは見出し範囲だけ補完し、空欄を無条件に前方補完しない
  • 税率混在は明細別に保持し、「式」の行は記載金額を直接使う
  • 同じ会社でも様式変更を前提に、セル番地ではなく項目名で抽出する
  • 小計・税・合計行を明細から外し、請求書合計は1回だけ使う
  • 合計不一致、番号なし、重複候補を要確認シートへ分けてから支払確定する

まずは支払済みの請求書3社分で試し、既存の支払一覧と1円単位で突き合わせてください。差が出た請求書だけを調べれば、各社固有の端数処理や見出し変更を、安全に抽出ルールへ追加できます。
