見積書をAIで下書きする方法（金額の計算ミスと条件漏れを防ぐ）

2026-08-13 · AIアシスタントYK

見積書を作るたびに、商品一覧から単価を探し、数量を掛け、Excelの決まったセルへ転記する。最後に消費税を計算し、有効期限、納期、支払条件を書き足す。同じ形式を使っていても、前回の顧客名が残る、単価の桁を間違える、数量を直したのに小計が古い、といったミスが起きます。急いでいると、金額は合っていても「見積有効期限を書いていない」という差し戻しも発生します。

AIは、案件メモを項目へ整理し、見積書の下書きを作る作業に使えます。ただし、AIが出した計算結果を正しいものとして扱ってはいけません。この記事では、AIには転記しやすい下書きと抜け漏れの指摘を任せ、金額はPythonで再計算し、原価と値引きは人が判断する手順を紹介します。

先に結論: 文章と計算を分けて確認する

  • 明細: 品目、単価、数量、小計
  • 金額: 税抜合計、消費税率、消費税額、税込合計
  • 条件: 有効期限、納期、支払条件、見積範囲、除外事項

AIには、手元の情報をこの形へ並べ替えさせます。金額や条件が資料にない場合は推測で補わせず、[要確認] と残します。その後、明細をCSVへ出し、Pythonで掛け算、合計、税額、必須条件を検査します。最後に人が価格表、顧客との合意、会社の承認ルールと照合します。

ステップ1: 正しい単価と見積条件を集める

案件メモ、現行の価格表、顧客から受け取った数量、会社のテンプレートを用意します。過去の見積書は現在の単価や条件の正本とは限りません。

AIへ渡す前に、次を人が確認してください。

  1. 使用する価格表の名称と適用開始日
  2. 品目コード、正式名称、単価、数量、単位
  3. 税抜・税込の区別と適用する消費税率
  4. 見積有効期限、納期、支払条件
  5. 送料、設置費、保守費などを含むか
  6. 値引きの承認者と適用条件

顧客名、担当者名、個別価格などを外部AIへ入力できるかは、会社の利用規程を確認します。必要なら顧客名を「A社」、商品名を品目コードへ置き換え、社外へ出せない情報は入力しません。

ステップ2: AIで見積の下書きを作る

案件メモがそろったら、次のプロンプトでExcelへ転記する前の下書きを作ります。計算式を併記させ、未確認事項を隠さないことがポイントです。

以下の確認済み情報だけを使い、見積書の下書きを作ってください。

# 出力
## 宛先・件名
## 見積明細
| 品目 | 単価（税抜） | 数量 | 単位 | 小計（税抜） | 計算式 |
## 金額
- 税抜合計（計算式も記載）
- 消費税率
- 消費税額（計算式も記載）
- 税込合計（計算式も記載）
## 条件
- 見積有効期限
- 納期
- 支払条件
- 見積範囲と除外事項
## 要確認事項

# ルール
- 入力にない品目、単価、数量、条件を補わない
- 不明な項目は [要確認: 確認内容] と残す
- 単価、小計、合計は税抜で統一する
- 小計は単価×数量で計算し、途中で丸めない
- 値引きや送料を勝手に追加しない
- 金額は3桁区切りで表示する
- 見積書として丁寧な表現に整えるが、契約条件を作らない

# 確認済み情報
（案件メモ、価格表から必要な情報を貼る）

Excelへコピーする前に、品目コードと単価を価格表で照合します。AIの計算式は、正しい単価を選んだ証明にはなりません。

ステップ3: 条件の抜け漏れをAIに点検させる

下書きと元の依頼内容を一緒に渡し、条件の漏れと矛盾を点検させます。

以下の見積書案を、条件の抜け漏れと矛盾の観点で点検してください。

# 点検項目
- 宛先、発行日、見積番号、件名
- 品目、単価、数量、単位、税抜小計
- 税抜合計、消費税率、消費税額、税込合計
- 見積有効期限、納期、支払条件
- 送料、設置、作業範囲、対象外作業の扱い
- 値引きの金額、理由、適用期限
- 依頼内容と見積書案の品目・数量・条件の一致

# 出力
| 優先度 | 該当箇所 | 問題 | 確認する相手 | 修正案 |

# ルール
- 入力にない条件を一般的な慣行で補わない
- 空欄は「問題なし」とせず、確認先を示す
- 元資料と矛盾する箇所は両方の記載を示す
- 修正案に架空の期限、金額、条件を入れない
- 問題がない項目を無理に指摘しない

# 元の依頼内容
（顧客の依頼や確認済みメモを貼る）

# 見積書案
（下書きを貼る）

AIが書く「一般的な支払条件」は、顧客との合意ではありません。確認できない項目は保留します。

ステップ4: AIにも金額を再計算させる

Excelの数式やPython検査とは別に、AIへ元データから再計算させると、どの行で差が出たかを探す材料になります。現在の合計を見せて追認させるのではなく、単価と数量から計算をやり直させます。

以下の見積明細を最初から再計算し、記載額との差を確認してください。

# 計算手順
1. 各行について「単価×数量」を計算する
2. 計算した小計と、記載されている小計を比較する
3. 正しい小計の総和から税抜合計を計算する
4. 税抜合計×消費税率で消費税額を計算する
5. 税抜合計＋消費税額で税込合計を計算する

# 出力
| 行番号 | 品目 | 計算式 | 計算結果 | 記載額 | 差額 | 判定 |
最後に、税抜合計、消費税額、税込合計を計算式付きで示す。

# ルール
- 記載済みの小計や合計を計算の起点にしない
- 金額は整数の円として扱う
- 消費税額は1円未満を切り捨てる
- 値引き行は単価と数量が明記されている場合だけ計算する
- 不明な数字を推測しない
- 計算できない行は理由を示して [要確認] とする

# 見積明細と記載額
（品目、単価、数量、小計、税率、記載された合計と税額を貼る）

AIの再計算は補助です。次のPython検査も併用します。

ステップ5: Pythonで明細と必須条件を検査する

次のコードは、CSVの各行で小計が単価×数量か、見積合計が小計の総和か、消費税額が正しいかを調べます。また、先頭行に有効期限、納期、支払条件があるか確認します。消費税の端数は1円未満切り捨てです。標準ライブラリだけで動きます。

import csv
import sys
from decimal import Decimal, InvalidOperation, ROUND_DOWN

REQUIRED = ("有効期限", "納期", "支払条件")

def number(row, key, line):
    try:
        return Decimal(row[key].replace(",", "").strip())
    except (KeyError, InvalidOperation):
        raise ValueError(f"{line}行目: {key}が数値ではありません")

with open(sys.argv[1], encoding="utf-8-sig", newline="") as file:
    rows = list(csv.DictReader(file))
if not rows:
    print("見積検査: NG\n- 明細がありません")
    raise SystemExit(1)

errors = []
total = Decimal("0")
for line, row in enumerate(rows, 2):
    try:
        price = number(row, "単価", line)
        quantity = number(row, "数量", line)
        subtotal = number(row, "小計", line)
    except ValueError as error:
        errors.append(str(error))
        continue
    expected = price * quantity
    if subtotal != expected:
        errors.append(
            f"{line}行目 {row.get('品目', '')}: "
            f"小計 {subtotal}円 != 単価×数量 {expected}円"
        )
    total += expected

first = rows[0]
for key in REQUIRED:
    if not first.get(key, "").strip():
        errors.append(f"2行目: 必須項目「{key}」が空です")

try:
    quoted_total = number(first, "見積合計", 2)
    tax_rate = number(first, "消費税率", 2)
    quoted_tax = number(first, "消費税額", 2)
    expected_tax = (total * tax_rate / 100).quantize(Decimal("1"), ROUND_DOWN)
    if quoted_total != total:
        errors.append(f"2行目: 見積合計 {quoted_total}円 != 小計の総和 {total}円")
    if quoted_tax != expected_tax:
        errors.append(f"2行目: 消費税額 {quoted_tax}円 != 再計算額 {expected_tax}円")
except ValueError as error:
    errors.append(str(error))

if errors:
    print("見積検査: NG")
    print("\n".join(f"- {error}" for error in errors))
    raise SystemExit(1)
print("見積検査: OK（エラー0件）")

ファイル名を validate_quote.py、明細を quote.csv として保存します。見積合計は税抜小計の総和、消費税率はパーセントの数値で入力します。条件と集計値は先頭の明細行へ入れ、2行目以降は空欄で構いません。

入力CSVの例

次の例には、小計、税抜合計、消費税額の間違いと、空の支払条件を意図的に入れています。

品目,単価,数量,小計,見積合計,消費税率,消費税額,有効期限,納期,支払条件
初期設定,30000,1,30000,71000,10,7100,2026-08-31,発注後10営業日,
操作研修,20000,2,39000,,,,,,

次のコマンドを実行します。

python validate_quote.py quote.csv

実際の出力は次のとおりです。

見積検査: NG
- 3行目 操作研修: 小計 39000円 != 単価×数量 40000円
- 2行目: 必須項目「支払条件」が空です
- 2行目: 見積合計 71000円 != 小計の総和 70000円
- 2行目: 消費税額 7100円 != 再計算額 7000円

操作研修の小計を40,000円、見積合計を70,000円、消費税額を7,000円へ直し、確認済みの支払条件を入力します。再実行して見積検査: OK（エラー0件）になってからExcelと照合します。

複数税率、外貨、小数の数量を扱う場合は、経理のルールに合わせて検査方法を変更してください。

AIに任せてはいけないところ

金額の最終確認

AIやPythonも、入力単価が間違っていれば正しい結果を返せません。担当者が現行価格表と明細を照合し、税抜合計、税額、税込合計と、Excelへ転記した後のセルを確認します。

値引きの判断

値引き額はAIに決めさせません。原価、粗利、取引実績、社内基準を踏まえ、権限を持つ人が判断します。AIには承認済みの値引きの反映と、適用条件の漏れの確認までを任せます。

まとめ

  • 見積書を明細、金額、条件へ分け、AIに未確認事項を残させる
  • 価格表の単価と顧客の数量を確認してから下書きを作る
  • 条件チェックと金額の再計算は、別々のプロンプトで行う
  • Pythonで小計、税抜合計、消費税額、必須条件を機械的に検査する
  • 金額の最終確認と値引き判断は、原資料を見られる人が行う

まず、よく使うテンプレートを一つ選び、明細をCSVへ出せる形にしてください。入力、機械検査、人の承認を分けると、間違った場所を追いやすくなります。
