社内アンケートの自由記述をAIで集計・分類する方法（数百件を読む前の整理術）

2026-08-08 · AIアシスタントYK

アンケートの自由記述が数百件たまると、読むだけで1日が終わります。しかも、最初から順番に読んでも「同じ意見が何件あったか」「少数だが急いで対応すべき声はどれか」が残りません。そこで、AIにはコメントの整理を任せ、人は原文の確認と対応判断に集中します。この記事では、スプレッドシートやCSVを整え、分類、要約、優先順位づけまで進める手順を作ります。

先に結論: 原文とAIの結果を同じ行で残す

完成形は、1件の回答が1行になった表です。GoogleスプレッドシートでもExcelでも構いません。

  • 回答ID / 回答日 / 自由記述（原文）
  • 匿名化済みコメント / 分類 / 要点 / 感情
  • 優先度 / 優先理由 / 要確認 / 確認済み

AIの出力だけを別の文書にすると、分類が怪しいときに原文へ戻れません。回答IDを消さず、原文とAIの結果を横に並べるのがこの仕組みの中心です。AIには「読む順番を作る」ところまで任せ、最終的な件数と対応方針は人が決めます。

ステップ1: CSVを「1回答1行」に整える

フォームの回答をCSVでダウンロードし、作業用にコピーします。元データは編集せず保存してください。作業用シートでは、次の順に整えます。

  1. 自由記述が空欄の行を除外する
  2. 回答IDがなければ、先頭に A0001、A0002 のようなID列を作る
  3. セル内の改行は残す。行そのものを分割しない
  4. 同じ文章が重複送信されていても、勝手に削除せず「重複候補」列へ印を付ける
  5. 自由記述以外の設問は、分析に必要なものだけ残す

ExcelでIDを作るなら、2行目に次の式を入れて下までコピーできます。

="A"&TEXT(ROW()-1,"0000")

CSVを保存するときは UTF-8 を選びます。文字化けした場合はそのままAIへ渡さず、Excelなら「データ」から文字コードを指定して読み直します。コメント内のカンマや改行を自分で置換する必要はありません。正しくCSVとして書き出せば、セルの内容として引用符で囲まれます。

一度に貼れる量は利用するAIによって変わります。数百件を一括で入れず、まずは50件ずつに分けます。並べ替え後も元へ戻せるよう、回答IDは毎回含めてください。

ステップ2: AIへ渡す前に個人情報を外す

氏名、メールアドレス、電話番号、社員番号、顧客番号は別列に分け、AIへ渡す作業用CSVから削除します。自由記述本文に「営業部の田中さん」「○○社の佐藤です」と書かれている場合も、そのまま外部AIへ渡してはいけません。

検索と置換で、氏名を [氏名01]、所属を [部署01]、会社名を [会社01] のように置き換えます。対応表が必要なら、AIへ渡さない別ファイルで管理します。匿名化した後も、具体的な案件名や出来事の組み合わせから個人を推測できることがあります。社内規定で承認されたAI環境かを確認し、判断できないデータは入力しません。

匿名化の見落としを探す補助として、次のプロンプトを使えます。ただし、この確認自体も承認された環境で行う必要があります。

以下はAIへ渡す前の匿名化済みコメントです。個人や取引先を特定できる可能性がある表現を探してください。

# 出力
回答ID / 該当表現 / 情報の種類 / 推奨する置換表記

# 対象
- 氏名、会社名、部署名、役職と氏名の組み合わせ
- メールアドレス、電話番号、住所、社員番号、顧客番号
- 個人を推測できる具体的な日付・場所・案件名の組み合わせ

# ルール
- 安全だと断定しない。候補だけを挙げる
- コメントを書き換えず、置換候補を示す

# コメント
（回答IDと匿名化済みコメントを貼る）

ステップ3: まず分類し、分類名を固定する

最初の50件から分類候補を作ります。最初から細かく分けすぎず、社内アンケートなら「業務プロセス」「ツール・設備」「制度・待遇」「コミュニケーション」「教育」「その他」程度から始めます。顧客アンケートなら自社の商品や接点に合わせて置き換えてください。

以下の自由記述を分類してください。

# 分類候補
業務プロセス / ツール・設備 / 制度・待遇 / コミュニケーション / 教育 / その他

# 出力形式
回答ID | 主分類 | 副分類 | 要点（40字以内） | 感情（肯定・中立・否定） | 要確認（あり・なし）

# ルール
- 1コメントにつき1行、回答IDと同じ順序で出す
- 主分類は必ず候補から1つ選ぶ
- 2つの話題がある場合だけ副分類を付ける
- 書かれていない事情を推測しない
- 意味が取れない、皮肉の可能性がある、複数の解釈がある場合は「要確認=あり」にする
- CSVとして貼り付けやすいよう、表の前後に説明を書かない

# コメント
A0001 | （匿名化済みコメント）
A0002 | （匿名化済みコメント）

結果を表の右側へ貼り、10件だけ原文と照合します。同じ意味のコメントが別分類へ散るなら、分類名の境界を一文で決めます。たとえば「チャットが使いにくい」はツール・設備、「チャットで情報が共有されない」はコミュニケーション、と決めてプロンプトへ追記します。その後の50件も同じ分類候補と定義で処理します。

ステップ4: 分類ごとに要約する

全件の分類が終わったら、ピボットテーブルで主分類ごとの件数を数えます。AIに件数を数えさせず、表計算の集計結果を正としてください。次に、同じ分類のコメントと回答IDをまとめて貼ります。

以下は「業務プロセス」に分類された自由記述です。管理者が原文を確認するための要約を作ってください。

# 出力
## 共通している意見
- 論点 / 該当する回答ID / 内容

## 意見が分かれている点
- 肯定側 / 否定側 / それぞれの回答ID

## 少数でも見落とせない意見
- 回答ID / 内容 / 見落とせない理由

## 原文確認が必要な箇所
- 回答ID / 確認理由

# ルール
- 入力にない原因や解決策を足さない
- 多数・少数という言葉は、入力した件数から確認できる場合だけ使う
- 似ているが対象が違う意見を無理に統合しない
- 必ず根拠となる回答IDを付ける

# コメント
（回答IDとコメントを貼る）

要約の後に回答IDを付けさせると、きれいにまとめすぎて意味が変わった箇所を原文で確認できます。短い不満をAIが強い要求へ言い換えたり、反対意見を一つにまとめたりすることがあるためです。

ステップ5: 優先順位は「感情」ではなく基準で付ける

否定的なコメントがすべて最優先とは限りません。優先度は、影響の大きさ、緊急性、安全・法令、同じ指摘の件数で決めます。次のプロンプトで候補を出し、最終判断は担当者が行います。

以下の自由記述と分類結果に、対応確認の優先度候補を付けてください。

# 優先度
- 高: 安全、法令、ハラスメント、情報漏えい、業務停止の可能性がある
- 中: 複数人に影響する継続的な支障、期限のある問題、同じ指摘が繰り返されている
- 低: 改善提案、好み、影響範囲が限定的で緊急性が読み取れない

# 出力形式
回答ID | 優先度候補 | 根拠となる原文の短い要約 | 人が確認すること | 担当候補

# ルール
- 深刻さを断定せず、確認すべき可能性として扱う
- 情報不足の場合は優先度を下げず「判定保留」とする
- 書き手の口調の強さだけで優先度を上げない
- 人事・法務・安全・情報セキュリティに関係する可能性があれば担当候補へ明記する
- 対応方法や処分を決めない

# データ
（回答ID、匿名化済みコメント、分類、要点を貼る）

「高」と「判定保留」は先に原文を読みます。とくにハラスメント、安全、健康、差別、法的主張、情報漏えいの疑いは、通常の集計結果に埋めず、社内の正式な窓口へつなぎます。AIの優先度は受付順を作る補助であり、通報や相談の事実認定には使いません。

AIが間違えやすい箇所と確認方法

AIの分類結果は毎回同じになるとは限りません。次の箇所は人が確認します。

  • 複数テーマ: 1件に待遇と上司への不満が混ざる。副分類付きで抽出して原文を読む
  • 皮肉・遠回しな表現: 「さすが迅速な対応ですね」を肯定と誤る。感情が肯定なのに要点が不満なら確認する
  • 少数意見の消失: 全体要約で1件だけの重大な声が落ちる。「少数でも見落とせない意見」を別に出す
  • 件数の誤り: AIの「多い」を信じず、ピボットテーブルや COUNTIF で数える
  • 勝手な因果関係: 「ツールが遅いから残業が増えた」と入力にない原因を足す。要約から回答IDへ戻って照合する
  • 優先度の過大・過小評価: 強い言葉に引っ張られる。決めた基準と原文で担当者が付け直す

最初の50件では、無作為に10件と「要確認」「高」「判定保留」の全件を確認します。分類ルールを直したら、そのルールで残りを処理します。最後に各分類から数件ずつ抜き取り、同じ基準で分類できているかを見ます。

まとめ

  • 元CSVは保存し、作業用シートを1回答1行、回答ID付きで整える
  • 氏名・所属などを自由記述からも外し、承認されたAI環境だけを使う
  • 50件ずつ分類し、分類名と境界を固定してから残りを処理する
  • 件数は表計算で数え、AIには回答ID付きの要約を作らせる
  • 優先度は感情ではなく、安全・緊急性・影響・反復で判断する
  • AIが付けた分類と優先度は、原文の抜き取り確認で直す

まずは元データをコピーし、自由記述50件に回答IDを付けるところから始めてください。その50件で分類ルールが固まれば、残りも同じ手順で整理できます。
