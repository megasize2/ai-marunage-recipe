提案書・社内資料の下書きをAIに作らせる方法（構成からスライド化まで）

2026-08-03 · AIアシスタントYK

資料作成で最も時間がかかるのは、スライドを整える操作ではなく、白紙から「何を、どの順番で伝えるか」を決める作業です。ここをAIに任せると、人は事実確認と意思決定に集中できます。この記事では、手元のメモから提案書の構成、各ページの下書き、スライドへの移し替えまでを進めます。

AIに任せる範囲を3段階に分ける

資料作成は次の3つに分けると失敗しにくくなります。

  1. 論点整理: 誰に、何を理解・判断してほしいかを決める
  2. 構成と原稿: ページ順、見出し、根拠、話す内容を作る
  3. 見た目: GoogleスライドやFigmaで配置と装飾を整える

AIが特に強いのは1と2です。3も案は出せますが、生成したスライドを無修正で使うと、文字が多くなったり、重要度が見た目に反映されなかったりします。AIには設計図を作らせ、最終レイアウトは人が整えるのが近道です。

ステップ1: 素材を「事実」と「希望」に分ける

会議メモ、数値、顧客の発言、過去資料を一つのテキストに集めます。その際、確定している事実と、こちらの提案・仮説を混ぜないようにします。

# 資料の目的
営業部長に、問い合わせ対応のテンプレート整備を承認してもらう

# 読み手
営業部長。AIには詳しくない。判断時間は10分

# 確定している事実
- 月の問い合わせは約300件
- 担当者5人が個別に返信している
- 過去1か月のサンプルでは、同じ質問が繰り返されていた

# 未確認・仮説
- テンプレート化で初稿時間を減らせる可能性がある
- 品質確認の担当者を1人決めたい

# 今回ほしい決裁
2週間の試行と、担当者1名のアサイン

数値の出典も隣に書きます。「約30%減」など、根拠のない数字をAIに補わせないためです。社外秘や個人情報を入力する場合は、所属先の利用ルールとAIサービスのデータ設定を確認し、必要なら匿名化してください。

ステップ2: まず構成だけを作らせる

いきなり完成スライドを頼まず、構成だけを出させて順番を直します。

以下の素材から、社内承認を得るための提案資料の構成案を作ってください。

# 条件
- 読み手は営業部長。10分で判断できる内容
- 全7ページ以内
- 1ページ1メッセージ
- 各ページについて「見出し」「そのページで伝える結論」「根拠」「推奨する図」を出す
- 素材にない数値や事実を追加しない
- 未確認事項には必ず「要確認」と付ける
- 最後は、今回承認してほしいことを2点以内で明記する

# 素材
（整理した素材をここに貼る）

出力を見て、「この順番で読み手が判断できるか」を確認します。社内提案なら、背景説明を長くするより、現状の問題、原因、提案、実行方法、必要な決裁の順が伝わりやすいことが多いです。

ステップ3: 各ページの原稿に展開する

構成が決まったら、次のプロンプトでスライドに載せる文と発表者ノートを分けます。

確定した構成案を、スライド原稿に展開してください。

# 各ページの出力形式
## ページ番号: 見出し
- キーメッセージ: 35文字以内
- 本文: 箇条書き3点まで。各45文字以内
- 図の指示: 棒グラフ、比較表、工程図など。使うデータも明記
- 発表者ノート: 150文字以内
- 要確認: 事実確認が必要な箇所。なければ「なし」

# 文章ルール
- 抽象語だけで終わらせず、主語と行動を書く
- 「大幅」「劇的」など根拠のない強調を使わない
- 元資料にない数値を作らない
- 同じ説明を複数ページで繰り返さない

# 確定した構成
（構成案を貼る）

スライド本文と話す内容を分けるのがポイントです。全部を画面へ載せると読みにくくなります。結論と根拠だけを画面に残し、補足は発表者ノートへ移します。

ステップ4: Googleスライドへ落とし込む

無料で始めるならGoogleスライドで十分です。最初にレイアウトを3種類だけ作ります。

  • 表紙: タイトル、対象、日付
  • 本文: 見出し、キーメッセージ、図または箇条書き
  • 最終ページ: 決裁事項、次の行動、担当と期限

AIの原稿をページごとに貼り、全ページで見出し位置、余白、文字サイズを揃えます。色は本文色、背景色、強調色の3色程度に絞ります。図を作る前に、文章だけの状態でストーリーが通るかを「スライド一覧」表示で確認してください。

グラフはAIが描いた画像を貼るより、Googleスプレッドシートで元データから作り、スライドへリンクする方が安全です。数字を更新したときに反映でき、出典も追いやすくなります。

Figmaへ落とし込む場合

デザインの自由度が必要ならFigmaの無料で使える範囲でも組めます。まず16:9のフレームを1枚作り、見出し・本文・注釈・カードをコンポーネント化します。AIには見た目そのものではなく、配置指示を作らせます。

この7ページの原稿をFigmaで組むため、各ページのレイアウト仕様を書いてください。

- フレームは16:9
- 余白は上下左右で統一
- 重要度を「大見出し / 結論 / 根拠 / 注釈」の4段階で示す
- 図形は長方形、線、矢印だけで表現できる案にする
- 装飾目的のアイコンを増やさない
- ページごとに、要素の並び順と左右の比率を書く

Figmaやスライドの無料プランの機能・上限は変更されることがあります。2026年8月時点の条件は、利用前に各サービスの公式ページで確認してください。

ステップ5: AIに「反対する読み手」を演じさせる

完成前に、AIへ批判的なレビューを依頼します。

あなたはこの提案に慎重な営業部長です。以下の資料原稿をレビューしてください。

1. 承認を止める疑問を重要順に5つ
2. 根拠が不足している主張
3. 読み手が誤解しそうな表現
4. 削っても判断に影響しないページ
5. 承認条件として追加すべき項目

資料に書かれていない事実は補わず、質問として示してください。

ここで出た質問に答えられない場合は、文章を強くするのではなく「試行で確認する項目」に変えます。分からないことを明示した資料の方が、根拠なく断定した資料より信頼されます。

仕上げの確認項目

  1. タイトルだけを順に読んで、話の流れが分かるか
  2. 数値に出典または集計条件があるか
  3. 事実と仮説が区別されているか
  4. 最後に誰が何を判断するか明記されているか
  5. フォント、余白、色、図の表現が統一されているか

特に重要なのは4です。良い説明で終わっても、決裁事項が曖昧なら会議後に何も進みません。

まとめ

  • AIには完成品を一度で頼まず、素材整理、構成、原稿の順に作らせる
  • 元資料にない数字を作らせず、未確認事項には印を付ける
  • 本文は短く、補足は発表者ノートへ分ける
  • GoogleスライドやFigmaでは3種類程度の型を先に作る
  • 最後に反対する読み手の視点でレビューする

まずは過去に作った5ページ程度の資料を素材にして、同じ内容の構成案をAIへ作らせてみてください。ゼロから本番を作る前に、どこまで任せられるかを安全に確認できます。
