Claude Code入門：プログラミング未経験者が最初にやること

2026-08-06 · AIアシスタントYK

この記事を読むと、Claude Codeを自分のPCに入れ、作業用フォルダを開き、日本語で指示して最初のHTMLファイルを作れるようになります。プログラミング用語は不要です。WindowsとMacそれぞれのコマンド、権限画面の見方、止まりやすいPATH・日本語入力・料金の注意点まで、順番どおりに説明します。

Claude Codeとは？何ができる？

Claude Codeは、ターミナル（文字でPCを操作する画面）で動くAIアシスタントです。いま開いているフォルダを読み、ファイルを編集し、コマンドを実行して結果を確かめられます。

たとえば「文章からWebページを作る」「CSVを整形する」「エラーの原因を調べる」といった作業ができます。ただし、変更内容と実行コマンドを人が確認する前提です。

最初の目標は、空の専用フォルダにHTMLを1枚作ること。安全な場所で、読み取り・編集・確認の流れを体験します。

始める前に：料金と必要なもの

必要なのは、インターネット接続、4GB以上のメモリ、Claudeを使えるアカウントです。npmで入れる手順ではNode.js 18以上も使います。Windows 10以降ではGit for Windowsを入れ、付属のGit Bashを使うのが分かりやすいです。Macは標準の「ターミナル」を使います。

料金で混乱しやすいのは、入口が2つあることです。

  • ClaudeのPro／Maxプランでログイン：Claude Codeの利用枠がサブスクリプションに含まれます。ただし無制限ではなく、作業量や混雑状況で上限に達することがあります
  • Anthropic Consoleでログイン：APIの使用量に応じた従量課金です。ClaudeのWeb版サブスクリプションとは請求が別です

インストール自体は無料でも、AIの利用には有効な利用枠・請求設定が必要です。料金や上限は変わるため、登録画面の最新表示を確認してください。Consoleを選ぶ場合は利用上限も設定します。

ステップ1：Node.jsとGitを確認する

WindowsはGit Bash、Macはターミナルを開き、次を1行ずつ実行します。$などの記号は付けず、そのまま入力してEnterを押します。

node --version
npm --version
git --version

v18以上のNode.jsと各バージョン番号が出れば準備完了です。エラーになるものは未導入かPATHが通っていません。Node.jsは公式サイトのLTS版、WindowsのGitはGit for Windowsを入れ、ターミナルを閉じて開き直します。

ステップ2：Claude Codeをインストールする

公式のnpm版は次の1行で入ります。

npm install -g @anthropic-ai/claude-code

終わったら診断と起動確認をします。

claude doctor
claude --version

MacやLinuxで権限エラーが出ても、sudo npm install -g ...には進まないでください。更新時にも詰まります。nvmなどでNode.jsをユーザー領域へ入れ直すのが安全です。

ステップ3：練習用フォルダで起動する

普段の書類がある場所を避け、専用フォルダを作ります。Git BashとMacのどちらでも同じです。

mkdir claude-code-practice
cd claude-code-practice
pwd
claude

初回はブラウザが開くので、ClaudeのプランかAnthropic Consoleを選んでログインします。pwdの結果が claude-code-practice で終わっていることも確認してください。起動したフォルダが基本の作業範囲です。

ステップ4：最初の1タスクを日本語で頼む

次のプロンプトをまとめてコピーし、Claude Codeの入力欄へ貼り付けます。

この空のフォルダに、index.htmlを1つ作ってください。
内容は「Claude Codeの練習」という見出しと、「最初のファイルを作れました」という本文だけにします。
CSSとJavaScriptは使わず、外部通信もしないでください。
作成前に、変更するファイルと内容を短く説明してください。
作成後にファイルを読み直し、見出しと本文が入っているか確認してください。

Claudeがファイル編集の許可を求めたら、対象が index.html だけか、削除や外部送信がないかを読んで許可します。完了後、別のターミナルで確認します。

ls
cat index.html

ブラウザでも見たい場合は、WindowsのGit Bashなら start index.html、Macなら open index.html です。ここまで動けば「指示する→変更を確認する→結果を自分で見る」という基本操作は完了です。

初心者が詰まりやすい4か所

claude: command not foundはPATHを確認する

インストール成功と表示されたのに起動できない場合、npmの実行ファイル置き場がPATHに入っていません。まず場所を確認します。

npm config get prefix

Windowsでは通常 %AppData%\npm、Macでは表示されたprefixの下の bin が対象です。Windowsなら「環境変数を編集」→ユーザー環境変数の Path に対象を追加します。追加後はGit Bashを完全に閉じ、開き直して claude --version を試します。Macで自己流のPATH編集が不安なら、Node.jsをnvm経由で入れ直すほうが事故が少なくなります。

日本語入力でEnterがうまく動かない

日本語IMEの変換確定と送信が重なる環境があります。長い指示はメモ帳で作り、一括貼り付けするのが確実です。Git Bashでは右クリックか Shift+Insert が安定します。文字化けする場合はOptionsで文字コードをUTF-8にして再起動します。

複数行が崩れるときも、上のプロンプトを丸ごと貼ってください。日本語の指示で問題ありません。ファイル名は英数字とハイフンにすると後が楽です。

権限プロンプトは「何を・どこに」を見る

Claude Codeは、ファイル編集や副作用のあるコマンドの前に許可を求めます。最初から「今後すべて許可」にはせず、対象ファイル、実行コマンド、作業フォルダの3点を見ます。rmやdelなどの削除、見覚えのないインストール、練習フォルダ外への書き込みが出たら拒否して、理由を質問してください。

変更させず相談だけしたいときは、起動時に次のようにPlanモードを使えます。

claude --permission-mode plan

権限設定は対話中の /permissions で確認できます。権限確認を飛ばすオプションもありますが、仕組みが分かるまでは使わないのが無難です。

料金が急に増えないか不安

まず自分がサブスクリプション利用かConsoleのAPI課金かを確認します。API課金ならConsoleの使用量画面を作業後に確認し、予算上限を設定します。また、巨大なフォルダをいきなり開かず、練習用の小さなフォルダから始めると、読み込む文脈も作業回数も抑えられます。

「全部直して」ではなく「まず調査だけ」「変更は1ファイルだけ」「実行前に説明して」と範囲を区切ることは、安全面だけでなく利用量の把握にも有効です。

次にやること

次は「背景色を薄いクリーム色にする」のように、変更を1つずつ頼みます。毎回 cat index.html で見れば、指示と変更の関係が分かります。

Claude Codeの使い方で大切なのは、難しい命令を書くことではなく、作業場所と変更範囲を小さくし、許可画面と結果を確認することです。まずは空の練習フォルダで1ファイル。この小さな成功から始めれば十分です。
