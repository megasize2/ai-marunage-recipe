売上集計をAIが書いたスプレッドシート関数とGASで自動化する方法（グラフまで更新）

2026-08-09 · AIアシスタントYK

売上CSVを貼り、店舗別に合計し、前月比を計算して、グラフを作り直す——毎月同じなら、人が繰り返す必要はありません。Googleスプレッドシートは関数だけでもかなり自動化でき、必要になったらGASを足せます。しかも式やコードはAIに書かせれば、自分で暗記しなくていい。この記事では、元データを壊さず、追加した売上が集計とグラフへ反映される仕組みを作ります。

最初にシートを3枚へ分ける

1枚ですべてを済ませると、貼り付けと集計がぶつかります。次の3枚に分けます。

  1. 売上明細: CSVを貼る原本。1行目は見出し
  2. 集計: 関数やピボットテーブルで店舗別・月別にまとめる
  3. ダッシュボード: 合計、前月比、グラフだけを見せる

例では「売上明細」の列を、A列=日付、B列=店舗、C列=商品、D列=数量、E列=単価とします。F列に金額を追加します。実際の見出しと違う場合は、AIへの依頼も必ず書き換えてください。

ステップ1: 配列数式で金額を自動計算する

F1に「金額」と入力し、F2へ次を入れます。

=ARRAYFORMULA(IF(A2:A="","",D2:D*E2:E))

これで行を追加するたびに金額が計算されます。各行へ式をコピーする必要はありません。F2より下へ手入力すると配列数式とぶつかるので、金額列は式専用にします。

AIへ式を書かせるときは、シート名、列、欲しい結果、空行の扱いを渡します。

Googleスプレッドシートの関数を書いてください。

# 元データ
- シート名: 売上明細
- 1行目は見出し
- A列: 日付、B列: 店舗、C列: 商品、D列: 数量、E列: 単価、F列: 金額
- 2行目以降にデータが増える

# 作りたい集計
- 「集計」シートのA1から出力
- 月ごと・店舗ごとの金額合計
- 行は年月、列は店舗、最後に合計列
- 空行は除外
- 元データへ行を追加したら自動で更新

# 出力条件
- まず推奨する関数を1本だけ提示
- 貼り付けるセルを明記
- 関数の各部分を初心者向けに説明
- 日本語ロケールで区切り文字のエラーが出る場合の直し方も説明

返ってきた式をいきなり本番へ入れず、シートをコピーして試します。#REF! が出たら、出力先に値が入っていないか確認します。

ステップ2: QUERY関数で月別・店舗別に集計する

日付から年月を作るため、「売上明細」のG1を「年月」、G2へ次を入れます。

=ARRAYFORMULA(IF(A2:A="","",TEXT(A2:A,"yyyy-mm")))

「集計」シートのA1には、次のようなQUERY関数を置けます。

=QUERY(売上明細!A:G,"select G, sum(F) where G is not null group by G pivot B label G '年月', sum(F) ''",1)

年月を行、店舗を列にして金額を合計します。店舗が増えても列が追加されます。関数の文字列では列名ではなくA〜Gを使うため、列を挿入したら式も見直してください。

集計結果の合計が正しいか、最初の月だけ電卓またはフィルタで手計算します。一度正しさを確認した式を毎月使い回すのが自動化です。

ステップ3: グラフは集計表を参照させる

「集計」の表を選び、メニューの「挿入」→「グラフ」を選びます。月別推移は折れ線、店舗比較は棒グラフが見やすいです。元データではなく集計表を参照させると、明細行が増えてもグラフが散らかりません。

確認する設定は3つです。

  • 1行目を見出しとして使用
  • 1列目をラベルとして使用
  • 金額の表示形式を通貨または桁区切りへ変更

意思決定に不要な3D効果や色数は増やしません。店舗数が多い場合は、売上上位5店舗と「その他」に絞った別表を作ります。

ステップ4: CSV取込をGASで自動化する

毎回CSVを貼る作業まで消したい場合はGASを使います。スプレッドシートの「拡張機能」→「Apps Script」を開き、AIが作ったコードを貼ります。次のプロンプトなら、Googleドライブの指定フォルダから未処理CSVだけを取り込むコードを依頼できます。

Google Apps Scriptで、売上CSVをスプレッドシートへ取り込むコードを書いてください。

# 対象
- GoogleドライブのフォルダID: ここにIDを入れる
- 対象ファイル: ファイル名が sales_ で始まり、拡張子が .csv
- CSVの文字コード: UTF-8
- CSVの列順: 日付 / 店舗 / 商品 / 数量 / 単価
- 書き込み先: このスプレッドシートの「売上明細」シート

# 処理
1. 1行目の見出しを除き、2行目以降へ追記
2. 取り込み済みファイルは再取込しない
3. 取込履歴シートに、ファイルID・ファイル名・取込日時・行数を記録
4. 途中で失敗したファイルは履歴へ成功として記録しない
5. 元のCSVは削除・移動・書き換えしない

# 条件
- 初回実行時に必要な権限と操作を説明する
- コードへ日本語コメントを入れる
- 最後に取り込んだファイル名と行数をログへ出す
- 同じファイルIDが履歴にあればスキップする

フォルダIDはドライブのURL中にある文字列です。社外へ見せてはいけないIDや実データはAIへ貼らず、ここにIDを入れる のままコードを作らせ、手元で置き換えます。

ステップ5: 時間主導トリガーで定期実行する

コードを一度手動実行し、期待どおり取り込めたら、Apps Scriptの「トリガー」から実行する関数と間隔を設定します。最初から自動実行にせず、テスト用CSVで次を確認します。

  1. 1ファイルだけ取り込める
  2. 同じファイルを再実行しても重複しない
  3. 列が欠けたCSVで安全に止まる
  4. 履歴の行数と実際の追加行数が一致する

トリガー実行は自分が見ていない時間に動きます。エラーを握りつぶさず、ログや通知を残すコードにします。

動かないときは式とエラーを丸ごと渡す

AIには「動きません」ではなく、式、貼ったセル、シート見出し、表示されたエラーを渡します。

Googleスプレッドシートの式でエラーが出ました。原因を切り分け、修正版を1つ提示してください。

# 式
（式を貼る）
# 貼ったセル
集計!A1
# 元シートの1行目
日付 / 店舗 / 商品 / 数量 / 単価 / 金額 / 年月
# エラー表示
（画面の文言をそのまま貼る）

GASなら実行ログの赤い部分を最初から最後まで貼ります。ただし、アクセストークンや個人情報が含まれていないか確認してください。

まとめ

  • 明細・集計・ダッシュボードを分け、元データへ式を混在させない
  • ARRAYFORMULAとQUERYで、行の追加に追従する集計を作る
  • グラフは明細ではなく集計表を参照する
  • CSV取込はGASで行い、ファイルIDの履歴で重複を防ぐ

まず関数だけで1か月分を正しく集計してください。そこが固まってからCSV取込をGASへ任せると、原因を切り分けやすく、壊れない仕組みになります。
