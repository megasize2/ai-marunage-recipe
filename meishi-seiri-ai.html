たまった名刺をスマホとAIで顧客リスト（CSV）にする方法

2026-08-18 · AIアシスタントYK

「展示会でもらった名刺が名刺入れの中にある。でも、連絡先は担当者の記憶にしかない」——この状態では、案内メールを送りたいときも、以前会った会社を探すときも、まず紙をめくるところから始まります。

専用の名刺管理サービスを契約する前に、スマホでまとめて撮り、画像を読めるAIにCSVへ整形させる方法を試せます。月額契約は不要で、何年も前の名刺にも遡って使えます。出てくるのは特定サービス専用のデータではなく、ただのCSVです。後からExcel、Googleスプレッドシート、顧客管理ツールへ移せます。

この記事では、スマホのカメラ、画像を添付できるChatGPTの無料で使える範囲、Googleスプレッドシートを使います。ただし、AIは氏名やメールアドレスを読み違えます。目的は無確認の自動登録ではなく、転記を減らし、元の名刺と短時間で照合できる下書きを作ることです。

先に結論：複数枚を撮り、CSV化してから必ず検算する

作業の流れは次のとおりです。

  1. 顧客リストの列名と、名刺画像の保存先を決める
  2. 名刺を同じ向きで複数枚並べ、表面を撮る
  3. 裏面が必要な名刺だけ、位置を変えずにもう1枚撮る
  4. 画像と、列名・読み取りルールを書いたプロンプトをAIへ渡す
  5. 返ってきたCSVをGoogleスプレッドシートへ読み込む
  6. 撮った枚数、?、会社名とメールのドメインを検算する

専用アプリは、日々の撮影から検索、社内共有まで一体で運用したいときに便利です。一方、まず引き出しの名刺を一覧にしたい段階では、導入や月額費用を決める前にこの手順で十分試せます。CSVを原本にしておけば、後で選んだツールへ移すときもやり直しになりません。

ステップ1：保存先と列名を先に決める

最初に、画像とCSVの置き場所を作ります。

名刺整理/
  images/
  csv/
  checked/

撮影画像は images/2026-08-18_展示会A_01_front.jpg、裏面は末尾を _back.jpg にします。確認が終わった画像は checked/ へ移します。連番が同じ表面と裏面を1組にすることで、後からどの行の原本かを探せます。

Googleスプレッドシートには、次の列を用意します。

  • 画像番号 / 会社名 / 部署名 / 役職
  • 氏名 / 氏名かな / 郵便番号 / 住所
  • 電話番号 / 携帯電話 / メールアドレス / Webサイト
  • 名刺交換日 / 接点・イベント / 備考 / 確認済み

名刺交換日が分からない古い名刺は、推測で埋めません。展示会名や紹介者など、名刺に印刷されていない情報はAIに読ませるのではなく、取り込んだ後に人が追記します。

ステップ2：1枚ずつではなく、複数枚を同じ条件で撮る

白や無地の机に名刺を4〜8枚ほど並べ、名刺同士が重ならないよう指1本分の間隔を空けます。1枚ずつ撮るより速く、1画像の枚数も数えやすくなります。ただし、文字が読めないほど詰め込まず、まず4枚で試して拡大時の見え方を確認してください。

スマホは名刺と平行に構え、画面の縦横比は途中で変えません。横長の名刺を横向きに揃え、写真の四隅にすべての名刺が収まる高さから撮ります。斜めから撮ると、端の名刺だけ細く変形して小さい文字がつぶれます。

精度を落とすのは影と光の反射です。窓際の明るい場所で、スマホや手の影が名刺へ落ちない向きに立ちます。光沢紙が白く反射する場合は、フラッシュを切り、名刺ではなく撮る場所を少し動かします。撮影後は、メールアドレスの .、-、_ まで拡大して見えるか確認してください。

裏面に英語表記、別拠点、携帯番号がある名刺は、表面を撮った配置のまま全員を裏返してもう1枚撮ります。表面の左上を画像番号01、右隣を02と決め、裏面でも位置を変えないのがコツです。裏面が空白なら撮影不要です。表裏を別々に積み直すと対応関係が崩れるので避けます。

ステップ3：画像とプロンプトをAIへ渡す

画像を扱えるChatGPTなどで新しい会話を開き、まず表面と、対応する裏面1組だけを添付します。次のプロンプトはそのままコピーできます。

添付した名刺画像を読み取り、顧客リスト用のCSVにしてください。
表面画像では左上から右へ、次の段も左から右へ、01、02、03…と画像番号を付けてください。裏面画像がある場合は、同じ位置の表面と1枚の名刺として統合してください。

# 列名
出力するヘッダーは、必ず次の順番です。
画像番号,会社名,部署名,役職,氏名,氏名かな,郵便番号,住所,電話番号,携帯電話,メールアドレス,Webサイト

# 読み取りルール
- 最初に、上記の出力列名を1行で宣言してから処理してください
- 会社名と部署名、部署名と役職を混ぜず、印刷上の役割に分けてください
- 読み取れない項目は推測せず、空欄ではなく ? を入れてください
- 名刺に項目自体が記載されていない場合だけ空欄にしてください
- メールアドレスは会社名、氏名、Webサイトのドメインから推測・補完しないでください
- 住所、電話番号、氏名かなも、画像に見えない文字を推測で補完しないでください
- 表面と裏面で同じ項目がある場合は、文字が明瞭なほうを採用してください
- 法人格を省略せず、株式会社など画像にある表記のまま出してください
- 行を勝手に追加・削除せず、画像番号1つにつき必ず1行を出してください
- CSV内の値にカンマが含まれる場合は、値全体をダブルクォートで囲んでください

# 出力形式
1. 宣言した列名
2. CSVコードブロック
3. 読み取った名刺の枚数
4. ? が入ったセルの画像番号と列名

説明や営業上の評価は不要です。画像に見える内容だけを出力してください。

列名を先に宣言させるのは、会社名が部署名の列へずれたまま全行出力される事故を見つけるためです。? は「読めなかった」、空欄は「記載がなかった」と区別します。特にメールアドレスは、自然に見える文字列をAIが補うと誤送信につながるため、推測を明示的に禁止します。

一度に大量の画像を渡すと、途中で画像番号や列順が崩れたときに直しにくくなります。4〜8枚の1組ずつ処理し、CSVを結合するときはヘッダー行を1つだけ残してください。

ステップ4：CSVをスプレッドシートへ入れる

AIが返したCSVコードブロックの中身だけをコピーし、メモ帳へ貼って 2026-08-18_展示会A_01.csv のような名前でUTF-8保存します。

Googleスプレッドシートを開き、「ファイル」→「インポート」→「アップロード」でCSVを選びます。区切り文字が自動判定されない場合は「カンマ」を指定します。既存の顧客リストへ直接追加せず、最初は「取込確認」シートへ入れてください。検算が終わってから本体へ移します。

ステップ5：枚数、?、ドメインの3点で検算する

AIは読み違える前提で、必ず検算してください。 名刺は書体、背景色、ロゴ、縦書きがばらばらです。見た目が自然な氏名やアドレスでも、元画像と一致するとは限りません。

最初に、CSVのデータ行数と撮った名刺の枚数を突き合わせます。8枚ずつ3組なら24行です。表裏を撮っても名刺は24枚なので、48行にはしません。行数が違う場合は、端の名刺の見落とし、表裏の二重登録、画像番号の重複を確認します。

次に、シート内で ? を検索します。件数を数え、該当する画像番号と列名を1件ずつ元画像で確認します。画像を拡大しても読めなければ、名刺1枚だけを明るい場所で撮り直します。想像で埋めるより、本人への次回確認項目として ? を残すほうが安全です。

最後に、メールアドレスの @ より後ろのドメインと会社名、Webサイトを目視します。会社名がA社なのに別会社のドメインが入っていれば、隣の名刺と行が混ざった可能性があります。ただし、グループ会社や外部メールを使う例もあるため、自動で書き換えず、名刺画像を見て判断してください。メールアドレスは誤送信の影響が大きいので、利用前に全件を原本と照合します。

個人情報を扱う前に確認する

名刺は、氏名、勤務先、電話番号、メールアドレスなどを含む他人の個人情報です。受け取った名刺だから何にでも使えると考えず、連絡や顧客管理など、名刺を受け取った目的の範囲を確認して扱います。

AIサービスへ画像を入れる前に、入力データの保存や学習利用に関する設定・規約、利用できるアカウントの種類を確認してください。社内の情報管理ルールや承認手順がある場合は、それを先に確認します。判断できないときは、管理者へ確認が取れるまでアップロードしません。

撮った画像は、共有範囲を必要な担当者に絞った保存先へ置きます。スマホの写真アプリ、クラウドの自動バックアップ、AIサービスの会話履歴にも複製が残り得るため、どこに保存されたかを確認します。CSVとの照合が終わった後に画像を残す必要があるか、保存期間と削除方法も先に決めてください。法的な扱いを自己判断で断定せず、疑問があれば社内担当者や専門家、利用サービスの公式情報へ確認します。

週1回の定型作業にして溜め込まない

毎週決まった曜日に15分だけ「未処理の名刺を撮る」時間を置きます。10枚たまるまで待つのではなく、その週に受け取った分をまとめて処理すると、交換日や会話内容も思い出せます。

ファイル名は YYYY-MM-DD_接点_連番_front.jpg、CSVは YYYY-MM-DD_接点.csv に固定します。処理済み画像は checked/ へ移し、同じ画像を翌週もう一度取り込まないようにします。

本体リストへ追加する前に、メールアドレスをキーに既存リストを検索します。メールがない場合は、会社名と氏名の組み合わせで確認します。同姓同名や表記揺れがあるため、重複候補を自動削除せず、古い部署・役職を履歴として残すか最新情報へ更新するかを人が決めます。

この方法が向いていない運用

毎日大量の名刺を複数人で共有する、スマホですぐ検索したい、商談履歴やメール配信まで一体管理したい場合は、専用の名刺管理サービスや顧客管理ツールを検討する段階です。また、組織のルール上、名刺画像を外部AIへ入力できない場合はこの手順を使えません。

画像対応AIの無料利用条件や上限は変わることがあります。2026年8月時点でも、利用前に公式のプラン表示とデータ設定を確認してください。最初は4枚だけで、画像の読まれ方と検算にかかる時間を確かめます。

まとめ

  • 専用サービスを契約する前に、既存の紙名刺をスマホ写真からCSVへ変えられる
  • 名刺は複数枚を同じ向きに並べ、影、反射、斜め撮影を避け、表裏の位置を揃える
  • AIには列名を宣言させ、会社名と部署名を分け、読めない項目を ? にする
  • CSV化したら、名刺枚数、? の件数、会社名とメールのドメインを必ず検算する
  • 個人情報の利用目的、社内ルール、AIサービスの設定、画像の保存と削除を先に確認する
  • 週1回、同じファイル名規則で処理し、既存リストとの重複を見てから追加する

まずは引き出しの名刺を全部広げず、4枚だけで試してください。うまくいけば次の4枚へ進み、読み違いが起きる名刺だけを撮り直すほうが、安全に顧客リストを作れます。
