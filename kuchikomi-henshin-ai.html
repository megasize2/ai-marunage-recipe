Googleマップの口コミ返信をAIで書く方法（低評価への返し方まで）

2026-08-20 · AIアシスタントYK

「口コミが来ているのは分かっている。でも、返信を考える時間がなくて未返信のまま」「低評価を見ると、何を書いても言い訳になりそうで手が止まる」——店舗を運営していると、口コミ返信は後回しになりやすい仕事です。

口コミ返信は、投稿者だけに向けた私信ではありません。書いている相手は投稿者ですが、あとから読むのは来店を検討している人です。星の数や不満の内容だけでなく、店が意見をどう受け止め、どう対応するかまで見られます。つまり返信は、次の客に店の姿勢を伝える文章でもあります。

この記事では、口コミをコピーし、AIに下書きを作らせ、人が手直ししてGoogleマップへ貼る方法を解説します。高評価、低評価、事実誤認がある低評価の3種類に使えるプロンプトも用意しました。目的は自動返信ではなく、止まっていた返信を、安全に出せる下書きへ変えることです。

先に結論：コピー、AI、手直しの3手で返信する

作業の流れは次のとおりです。

  1. Googleマップの口コミ本文と星の数をコピーする
  2. 店の事情と書き方を指定したプロンプトと一緒にAIへ渡す
  3. 固有の事実を1つ足し、全文を確認してから返信欄へ貼る

AIにGoogleビジネスプロフィールを直接操作させる必要はありません。口コミのコピーと返信の貼り付けは人が行い、AIには下書きだけを任せます。この分け方なら、別の口コミへ誤投稿する事故や、確認前の文章が公開される事故を避けられます。

返信前に、口コミをそのままAIへ渡してよいかも確認してください。口コミ本文が公開されていても、予約名、電話番号、来店日時など、自店だけが持つ顧客情報まで追加する必要はありません。実在の顧客名はAIへ渡さず、「投稿者」「お客様」のままで十分です。

テンプレ1：高評価の口コミへ返信する

高評価への返信は、お礼だけで終わらせず、投稿者が触れた商品や接客を1つ拾います。「ご来店ありがとうございました。またのお越しをお待ちしております」が何件も並ぶより、店の様子が次の客へ伝わります。

次のプロンプトはそのままコピーできます。【 】の中だけ、自店と今回の口コミに合わせて書き換えてください。

以下のGoogleマップの口コミに対する、店舗からの返信文を書いてください。

# 口コミ
【ここに口コミ本文を貼る】
星の数: 【例: 5】

# 店舗情報
- 店名: 【店名】
- 業種: 【例: イタリアン / 美容室 / 整体院 / 雑貨店】
- 口コミに関連する事実: 【例: ランチの自家製ラザニアを注文された / カラーを担当した】
- 今回伝えたいこと: 【例: 季節メニューも用意している / 次回は別のスタイルも相談してほしい】

# 書き方の指定
- 120〜180文字
- 冒頭でお礼を伝える
- 口コミに書かれた具体的な内容を1つ拾う
- 店の宣伝を長く書かない
- 「スタッフ一同」「励みになります」「またのご来店を心よりお待ちしております」は合計1回まで
- 投稿者の名前は書かない
- 返信文だけを出力する

書き換えるのは「口コミ」「星の数」「店名」「業種」「関連する事実」「今回伝えたいこと」です。関連する事実が思い出せない場合は、推測せず「不明」と入れてください。AIに架空の接客内容を作らせるより、口コミ内のメニュー名を拾うだけのほうが安全です。

テンプレ2：低評価の口コミへ返信する

低評価への返信では、謝罪の量を増やすより、何について謝り、何を見直したかを短く書くことが重要です。店の全面的な非を認める必要はありません。確認できた不快な体験や案内不足に範囲を限定します。

以下のGoogleマップの低評価口コミに対する、店舗からの返信文を書いてください。

# 口コミ
【ここに口コミ本文を貼る】
星の数: 【例: 1】

# 店舗情報
- 店名: 【店名】
- 業種: 【業種】
- 店で確認できたこと: 【例: 混雑時に案内が遅れた / 会計時の説明が不足していた / 確認できていない】
- すでに改善したこと: 【例: 受付時に待ち時間を伝える運用へ変更した / まだ改善策は決まっていない】
- 公開返信で謝る範囲: 【例: 長く待たせたこと / 説明不足で不安にさせたこと】

# 書き方の指定
- 150〜220文字
- 最初に、指定した範囲についてだけ謝る
- 投稿者の感じ方を否定しない
- 言い訳、反論、責任転嫁を書かない
- 改善策は、すでに実施した事実だけを書く
- 個人情報、予約情報、来店記録、担当者名を書かない
- 返金や補償など、確約していない対応を提案しない
- 「貴重なご意見」「真摯に受け止め」は合計1回まで
- 返信文だけを出力する

まだ改善していないことを「改善に努めます」で埋めると、次の客には定型的な火消しに見えます。改善策が決まっていなければ無理に書かず、「店内で内容を共有し、案内方法を確認します」など、今から本当に行う確認だけを書きます。

テンプレ3：事実誤認がある低評価へ返信する

口コミの内容が事実と違っていても、公開の返信欄で勝ち負けを決めようとしないでください。訂正するのは、営業時間、提供内容、料金体系など、次の客が誤解すると困る点だけです。投稿者の人物像や来店の有無を断定する必要はありません。

以下のGoogleマップの低評価口コミには、店舗側で確認した事実と異なる記述があります。
感情的に反論せず、必要な点だけを訂正する返信文を書いてください。

# 口コミ
【ここに口コミ本文を貼る】
星の数: 【例: 1】

# 店舗情報
- 店名: 【店名】
- 業種: 【業種】
- 口コミに書かれた内容: 【例: 予約客しか入店できないと書かれている】
- 店で公開している正しい情報: 【例: 予約なしでも利用可能。ただし混雑時は待ち時間がある】
- こちらで確認できないこと: 【例: 投稿者の来店日時や当日の会話】
- 必要なら案内する公式な確認先: 【例: 店舗の問い合わせフォーム / 書かない】

# 書き方の指定
- 150〜220文字
- 不快な思いをさせた可能性へのお詫びは1文まで
- 「当店の案内は〜です」「現在は〜としております」の形で、公開情報だけを静かに訂正する
- 「そのような事実はない」「来店記録がない」「虚偽」「営業妨害」と書かない
- 投稿者の個人情報、予約情報、来店記録、担当者名を書かない
- 削除や投稿の修正を要求しない
- 返信文だけを出力する

書き方の型は、受け止める → 公開情報を訂正する → 必要なら確認先を案内するの順です。たとえば「ご案内が分かりにくく、ご不快な思いをおかけしました。当店は予約なしでもご利用いただけますが、混雑時にはお待ちいただく場合があります。案内表示も改めて確認いたします」と書けば、相手を責めずに次の客の誤解を解けます。

AIの文章へ「その店だけの事実」を1つ足す

AIが作った返信をそのまま貼ると、「ご来店ありがとうございます」「貴重なご意見をありがとうございます」「スタッフ一同努めてまいります」といった定型句が並びます。同じ言葉の返信が10件続くと、返信数は増えても、一件ずつ読んでいない印象を与えます。

直し方は難しくありません。その口コミに固有の事実を1つ入れるだけです。

  • 飲食店なら、注文されたメニュー名や、褒められた味付け
  • 美容室なら、相談された髪型や、施術後に伝えた手入れ方法
  • 整体なら、説明したセルフケアの種類（症状や診断名は書かない）
  • 小売店なら、購入された商品の種類や、店頭で案内した使い方

「先日は季節のパスタをお選びいただき、ありがとうございました」のように1文変えるだけで、その返信は別物になります。ただし、その日の担当者名、予約時刻、購入金額など、本人を特定し得る情報は公開返信へ書きません。固有性を出すことと、個人情報を出すことは別です。

公開前には、口コミ本文とAIの返信を横に並べて読みます。メニュー名が正しいか、実施していない改善を約束していないか、投稿者が書いていない事情を補っていないかを確認してください。

低評価は「謝る範囲」を先に決める

低評価を見ると、全面的に謝るか、全面的に反論するかの二択になりがちです。実際には、その間にある書き方が使えます。

まず、確認できた不備を1つに絞ります。「お待たせしたこと」「説明が不足したこと」「不快な思いをさせたこと」のように、謝る対象を限定します。「すべて当店の責任です」「二度と起こしません」といった広すぎる表現は、確認できていない事実まで認める文章になります。

次に、言い訳を書きません。「人手不足で」「新人が担当して」「他のお客様の対応が重なり」は店側の事情です。事実でも、公開返信では不満を打ち消す材料になりません。書くなら、原因ではなく実施済みの改善です。「混雑時は受付時に待ち時間をお伝えする運用へ変更しました」のように、変えた行動だけを示します。

事実が違う場合も、予約台帳や防犯カメラを根拠に相手を追い詰めません。「該当する来店記録がありません」と書くと、別名予約や同行者の可能性まで公開で争うことになります。訂正は「当店では全商品に追加料金がかかるとの記載がありますが、追加料金の対象は一部オプションのみです」のように、次の客に必要な公開情報へ絞ります。

やってはいけないこと

1. 投稿者と返信欄で口論する

反論を重ねるほど、口コミの内容より店の対応が読まれます。返信は一度で要点を伝え、個別確認が必要なら公式の問い合わせ先を案内します。相手の言葉遣いをまねたり、皮肉で返したりしません。

2. 削除依頼を最初の手段にする

気に入らない低評価だからという理由だけで、まず削除を求める運用にはしません。明らかなスパムや規約違反が疑われる場合は、公開返信で投稿者へ削除を迫らず、Googleの正式な報告手順と最新のポリシーを確認します。報告する場合でも、返信が必要かは別に判断します。

3. サクラや自作自演で評価を埋める

実際の体験に基づかない口コミを依頼したり、自店や関係者で高評価を投稿したりすると、信用を失うだけでなく、プラットフォーム上の措置につながるおそれがあります。低評価を隠すための偽レビューではなく、実際の客へ公平な方法で感想をお願いし、返信とサービス改善を積み重ねます。

4. AIへ実在の顧客名や来店記録を渡す

返信文を作るために必要なのは、公開された口コミと店側の回答方針です。実名、電話番号、予約番号、購入履歴、施術記録を貼る必要はありません。「投稿者A」「ある日の来店」のように伏せ、会社や店舗でAI利用ルールがある場合はそちらを優先してください。

週1回15分の定型作業にする

口コミが来るたびに返信しようとすると、通常業務に埋もれます。毎週決まった曜日に15分だけ、未返信をまとめて処理する時間を置きます。

返信の型は、高評価用、低評価用、事実誤認がある低評価用の3つをテキストファイルへ保存します。毎回ゼロからプロンプトを作らず、【 】だけを書き換えます。AIの下書きを3件ほどまとめて作り、1件ずつ固有の事実を足して公開します。同じ定型句が連続していたら、語尾や拾う事実を変えます。

ただし、低評価だけは当日中に内容を見ます。当日中に必ず返信するという意味ではありません。個人情報の掲載、店舗の安全に関わる指摘、同じ不具合の連続など、すぐ確認すべき内容がないかを見るためです。事実確認が必要なら、焦って返さず、店内で確認してから短く返信します。

15分で全部終わらない週は、古い高評価より新しい低評価を先に扱います。未返信件数をゼロにすることより、誤った返信を出さないことを優先してください。

まとめ

  • 口コミ返信は投稿者への返事であると同時に、来店を検討する次の客へ店の姿勢を伝える文章
  • 口コミをコピーし、AIへ渡し、固有の事実を1つ足してから貼る3手で進める
  • 高評価、低評価、事実誤認がある低評価の3つのプロンプトを使い分ける
  • 低評価では謝る範囲を限定し、言い訳ではなく実施済みの改善だけを書く
  • 事実が違うときは相手を責めず、次の客に必要な公開情報だけを静かに訂正する
  • 投稿者と口論せず、削除依頼や自作自演を安易な解決策にせず、顧客情報をAIへ渡さない
  • 週1回15分でまとめて返し、低評価だけは当日中に内容を確認する

まずは未返信の高評価を1件だけコピーし、テンプレ1へ入れてください。AIの下書きにメニュー名や施術内容を1つ足せば、定型文ではない返信を数分で出せます。
