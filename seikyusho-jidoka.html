請求書・見積書の作成を自動化する無料の仕組み（テンプレ＋AIで月末が10分に）

2026-08-02 · AIアシスタントYK

月末に請求書を10社ぶん、Excelのテンプレを開いて名前と金額を書き換えて、PDFにして、メール文を書いて送る——この一連の作業、明細データさえ用意すれば、あとは全部自動にできます。しかも無料で。この記事では、そのための仕組みの作り方を、コピペで使えるプロンプトと一緒に解説します。

自動化する範囲を決める

請求書業務は4工程に分かれます。全部を一気に自動化しようとすると挫折するので、順番に潰します。

  1. 明細を集める（何をいくらで請求するか）
  2. 書類を作る（テンプレに流し込んでPDF化）
  3. 送る（メール本文を書いて添付）
  4. 記録する（送付済み・入金済みの管理）

このうち 2と3はほぼ完全に自動化でき、4は半自動、1だけは人の判断が残る、というのが現実的な線引きです。逆に言えば、「今月はA社に何を請求するか」さえ決まれば、残りは機械の仕事にできます。

ステップ1: 明細を1枚のスプレッドシートに集約する

まず、請求先ごとにバラバラだった情報を、1枚の表に統一します。Googleスプレッドシートでも Excel でも構いません。列はこれだけあれば足ります。

  • 請求先名 / 敬称（御中・様）
  • 件名（例: 2026年7月分 保守運用費）
  • 品目 / 数量 / 単価
  • 税率（10% か 8%）
  • 支払期限
  • 請求書番号

この表が仕組みの中心です。ここが整っていないと後工程は自動化できません。逆にここさえ埋まれば、あとは流し込むだけになります。

「毎月同じ内容」の顧客が多いなら、前月分をコピーして金額だけ直す運用にすると、ここの入力も1〜2分で終わります。

ステップ2: 無料ツールで書類を作る（3つの選択肢）

作り方は3通りあり、件数と好みで選びます。

  • クラウド請求書サービスの無料枠: 月あたりの発行件数に制限のある無料プランを提供しているサービスがあります。件数が少ないならこれが最速で、テンプレも制度対応済み。ただし無料枠の条件は変わるため、申し込み前に必ず現在のプラン内容を確認してください
  • スプレッドシート＋差し込み: Googleスプレッドシートのテンプレートに、上の表から値を差し込んでPDF出力する方法。追加費用ゼロ。Google Apps Script を使えばPDF化とドライブ保存まで自動化できます
  • Pythonで一括生成: 件数が多い、あるいはレイアウトを自分で完全に決めたい場合。テンプレのExcelに値を書き込んでPDF化するスクリプトをAIに書かせます

10社程度までならスプレッドシート方式、それ以上ならPython方式が快適です。

ステップ3: 生成スクリプトをAIに書かせる（コピペ用プロンプト）

Python方式のプロンプトです。ポイントはテンプレのどのセルに何を入れるかを明示すること。ここを曖昧にすると使えないコードが返ってきます。

Pythonで請求書を一括生成するスクリプトを書いてください。

# 入力
- C:\work\請求明細.xlsx の「明細」シート
- 列: 請求先名 / 敬称 / 件名 / 品目 / 数量 / 単価 / 税率 / 支払期限 / 請求書番号
- 同じ請求先名の行が複数ある場合は、1枚の請求書の明細行としてまとめる

# テンプレート
- C:\work\template.xlsx を雛形として使う（元ファイルは書き換えない）
- 差し込み先セル: B3=請求先名+敬称 / B5=件名 / B7=請求書番号 / B8=発行日(実行日) / B9=支払期限
- 明細は A15 から下方向に 品目 / 数量 / 単価 / 金額(数量×単価)
- 明細の下に 小計 / 消費税額（税率ごとに分けて計算）/ 合計

# 出力
- C:\work\out\ に「請求書_請求先名_YYYYMM.xlsx」の名前で1社1ファイル保存
- 出力フォルダが無ければ作る

# 条件
- 環境は Windows / Python 3.12 / openpyxl 使用可
- 金額は円単位、消費税は税率ごとに小計してから端数切り捨て
- 生成したファイル名と合計金額を最後に一覧表示する

最後の「一覧表示する」の1行が効きます。金額の桁を間違えたまま10社に送る事故を、送信前に発見できます。

PDF化まで自動でやりたい場合は、Excelを経由せず直接PDFを組み立てる方が安定します。「レイアウトは同じで、出力をPDFにしてください。PDF生成ライブラリは環境に入れやすいものを選んで、必要なインストールコマンドも教えてください」と続けて頼めば書き換えてくれます。

ステップ4: 送付メールもAIに書かせる

書類ができたら送付文です。これは毎回ほぼ同じなので、プロンプトを固定しておきます。

請求書送付のメール本文を書いてください。

# 情報
- 宛先: A株式会社 ご担当者様
- 件名にあたる内容: 2026年7月分 保守運用費の請求書送付
- 請求金額: 165,000円（税込）
- 支払期限: 2026年8月31日
- 添付: 請求書PDF 1通

# 書き方の指定
- 本文は8行以内。時候の挨拶は不要
- 金額と支払期限は本文中に明記する（添付を開かなくても分かるように）
- 件名も1行提案する
- 「ご査収のほどよろしくお願いいたします」で締める

金額と期限を本文にも書かせるのは、相手が添付を開かずに処理できるようにするためです。これだけで入金の遅れが目に見えて減りました。

見落とすと事故になる: 請求書の必須記載項目

自動化で怖いのは、間違った書式のまま全社ぶん量産してしまうことです。日本の消費税のインボイス制度（適格請求書等保存方式）では、適格請求書に記載すべき項目が定められています。おおむね次のとおりです。

  1. 発行者の氏名または名称、および登録番号
  2. 取引年月日
  3. 取引内容（軽減税率対象ならその旨）
  4. 税率ごとに区分して合計した対価の額と、適用税率
  5. 税率ごとに区分した消費税額等
  6. 交付を受ける事業者の氏名または名称

特に落としやすいのが登録番号と税率ごとの区分表示です。テンプレートを作った時点で1枚だけ出力し、この6項目がすべて入っているかを目視でチェックしてください。ここさえ通れば、あとは何百枚出しても同じ品質になります。

なお、制度の詳細や自分が適格請求書発行事業者に該当するかは、国税庁の公式情報と顧問税理士の確認が最優先です。この記事は仕組みの作り方の話であって、税務の判断はここではできません。

運用で効いた3つのルール

1. 請求書番号は機械に採番させる

手で付けると必ず重複か抜けが起きます。「YYYYMM-連番」の形式でスクリプトに振らせ、発行済みの番号は一覧に記録する。監査のときに効きます。

2. 送信前に必ず1枚は開いて見る

全ファイルを確認する必要はありませんが、毎回1枚だけは実際に開いてレイアウト崩れと金額を確認する。テンプレを触った月ほど崩れます。この1分を惜しむと、10社への謝罪メールになります。

3. 送付済み・入金済みは同じ表で管理する

新しい管理ツールを増やさず、ステップ1の表に「送付日」「入金日」の列を足すだけにします。未入金の抽出はフィルタ一発。督促メールの下書きも、この表の行をAIに貼れば作れます。

まとめ

  • 明細を1枚の表に集約する。ここが仕組みの中心で、唯一人がやる工程
  • 書類生成はスプレッドシート差し込みかPythonで自動化。テンプレのセル位置をAIに明示するのがコツ
  • 送付メールは固定プロンプトで生成。金額と期限は本文にも書く
  • 必須記載項目（特に登録番号と税率ごとの区分）はテンプレ完成時に1枚だけ目視チェック

月末の2時間が10分になります。まずは請求先3社ぶんの表を作るところから始めてみてください。
