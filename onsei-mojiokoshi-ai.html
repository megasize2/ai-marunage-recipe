会議や取材の録音を無料AIで文字起こしする方法（話者分けと誤字修正まで）

2026-08-09 · AIアシスタントYK

1時間の会議を聞き直して文字にすると、再生時間の何倍もかかります。音声認識を使えば下書きは短時間で作れますが、録音が悪いままでは、どのAIを使っても正確にはなりません。この記事では、無料または手元の環境で使える方法を選び、話者を分け、誤字を効率よく直して使える記録へ仕上げる手順を解説します。

まず選ぶ: 手軽さか、機密性か

無料で始める方法は大きく3つです。

  • Web会議ツールの字幕・文字起こし機能: 会議中に記録でき、準備が少ない。利用できる機能は契約や管理者設定で変わるため、会議前に確認する
  • ChatGPTなど音声ファイルを扱えるAIの無料枠: ファイルを添付して試しやすい。ただし容量や利用回数の条件は変わるので、画面の案内を確認する
  • Whisperを自分のPCで動かす: 音声を外部サービスへ送らず処理しやすい。導入と処理時間は必要だが、機密性を重視するときの選択肢になる

公開可能な短い録音ならクラウド型、社外秘の会議なら会社が承認した環境かローカル処理を選びます。無料かどうかより、録音データをどこへ送ってよいかが先です。

ステップ1: 文字起こししやすく録音する

精度は録音時点でほぼ決まります。次の4点だけ守ります。

  1. マイクを発言者の中央に置き、机の端へ置かない
  2. PCのファン、空調、食器の音から離す
  3. 参加者に名前を名乗ってから最初の発言をしてもらう
  4. 固有名詞が出たら、その場で一度ゆっくり言い直す

オンライン会議では、スピーカーから出した音を別のスマホで録るより、会議ツールの録画・録音機能を使う方が声を明瞭に残せます。録音前には参加者へ目的と保存先を伝え、同意を取ってください。

テストとして30秒録り、自分でイヤホンから聞きます。人が聞き取れない音はAIにも直せません。

ステップ2: Whisperを無料で動かす

自分のPCで処理する例です。Pythonをインストールした環境で、PowerShellを開いて次を実行します。

pip install -U openai-whisper

Whisperは音声の読み込みにFFmpegを使います。FFmpegを別途インストールし、ffmpeg -version で確認できる状態にします。準備ができたら、音声ファイルのあるフォルダで次を実行します。

whisper meeting.m4a --language Japanese --model small --output_format txt,srt

txt は通読用、srt は時刻付きの確認用です。PCで処理が重い場合は --model base に下げます。精度と処理時間は録音やPC性能で変わるため、まず5分の音声で試してください。

クラウド型AIを使う場合も、音声を添付して「逐語録と時刻付き要約を作る」と指示します。長い音声が受け付けられなければ、音声編集ソフトで30分程度に分け、ファイル名へ順番を付けます。

ステップ3: 話者分けは手がかりを渡す

音声だけで完全な話者分けを期待すると、似た声や短い相づちで崩れます。参加者名、役割、最初の発言をAIへ渡します。

以下は会議の文字起こしです。内容を省略せず、話者を整理した読みやすい逐語録に直してください。

# 参加者
- 田中（進行、営業）: 最初に議題を説明した人
- 佐藤（開発）: 技術的な制約を説明した人
- 鈴木（顧客）: 導入時期と予算を質問した人

# 修正ルール
- 話者を確定できる発言は「田中:」の形式にする
- 確定できない発言は推測せず「話者不明:」にする
- 「えー」「あのー」など意味のない言葉だけ削除する
- 発言の意味、数値、否定表現は変えない
- 聞き取れない箇所は [聞き取り不明 00:12:34] と残す
- 5分ごと、または話題が変わる箇所に時刻を残す

# 文字起こし
（ここに時刻付きの文字起こしを貼る）

「分からなければ話者不明」と指定するのが重要です。誤った名前を付けるより、あとでその箇所だけ音声を聞く方が安全です。

ステップ4: 誤字は固有名詞リストで一括修正する

文字起こしが間違えやすいのは、人名、社名、商品名、英字、数字です。会議前に正しい表記を10〜20語だけ用意します。

次の文字起こしを校正してください。

# 正しい表記
- 青葉ソリューションズ
- Project Cedar
- SSO
- 月額48万円
- 2026年10月1日

# ルール
- 正しい表記リストに照らして誤変換を直す
- 文脈だけで断定できない語は勝手に直さず【要確認】を付ける
- 数字、日付、金額、固有名詞を変更した箇所は最後に一覧化する
- 要約や言い換えはしない

（ここに文字起こしを貼る）

修正一覧があれば、全文を読み比べなくても重要箇所だけ確認できます。特に金額、日付、数量、担当者名は音声へ戻って聞きます。

ステップ5: 逐語録と議事録を分けて保存する

文字起こしをそのまま議事録にすると長すぎます。用途を分けます。

  • 逐語録: 発言の確認用。時刻と話者を残し、内容を省略しない
  • 議事録: 決定事項、担当者、期限、未決事項だけにする
  • 取材原稿メモ: 引用候補を時刻付きで抜き出す

逐語録を保存してから、そのコピーをAIへ渡して議事録を作ります。要約後の文章だけを残すと、「本当にそう言ったか」を確認できません。

よくある失敗と直し方

声が重なって文章が抜ける

重なった部分だけSRTの時刻から探し、音声を聞いて手で補います。全体を再処理するより速く終わります。次回は進行役が一人ずつ発言するよう促します。

専門用語が毎回違う漢字になる

正しい表記リストを先に渡します。同じ誤りが多い場合は「誤: ○○ / 正: △△」の置換表を作り、テキストエディタの一括置換も使います。

AIが読みやすくしすぎて意味が変わる

「否定、保留、推測を断定へ変えない」「発言内容を追加しない」と指示します。契約、採用、取材引用など証拠性が必要な場面は、原音を最優先にします。

まとめ

  • ツール選びの前に、録音を外部へ送ってよいか確認する
  • マイク位置、雑音、名乗り方を整えると認識精度が上がる
  • 話者を断定できない箇所は「話者不明」、聞けない箇所は時刻付きで残す
  • 固有名詞リストを渡し、数字・日付・金額だけ原音で確認する

まず5分の録音で、文字起こしから修正まで一周してください。短い音声で自社向けの固有名詞リストを作ると、次の1時間会議がぐっと楽になります。
